# AI 助手连接方式

AI 助手同时兼容云端网页 API 与本地模型，新用户默认进入 OpenRouter 云端配置，本地 Ollama、LM Studio 和其他 OpenAI 兼容服务仍可在设置中切换。

## 云端优先模式

- 默认提供商为 OpenRouter，需要用户自己的 API Key。
- 默认模型路由为 `openrouter/auto`，也可选择 `openrouter/free`。
- API Key仅保存在当前浏览器会话存储中，不写入持久化配置。
- 每次请求只发送当前对话、系统提示和所选芯片信息，不会自动读取或上传本地工程文件。
- 未填写有效 API Key 时禁止发送，不使用静态模板或模拟回答代替真实模型。

## 本地模式

- 支持通过 Local Agent 检测 Ollama、LM Studio 等本地服务及其已安装模型。
- Ollama服务运行但没有模型时会明确提示安装模型，不会误报为已配置。
- 也可填写其他OpenAI兼容本地端点；无法检测的服务需要用户自行确认地址、模型和CORS配置。

切换提供商时会清空上一云端提供商的API Key，避免把一个服务的凭据发送给另一个服务。清除配置后恢复为云端优先模式。
