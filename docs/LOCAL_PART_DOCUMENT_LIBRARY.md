# 本地器件资料库

资料中心按完整型号展示厂商官方资料，也允许用户导入已经从嘉立创、半导小芯、厂商网站或其他渠道合法取得的 PDF。导入文件仅在当前浏览器的 IndexedDB 中保存，不发送给 Local Agent、外部 AI 或在线服务。

## 使用流程

1. 在资料中心输入完整器件型号并打开型号详情。
2. 在“官方技术资料”区域选择“导入本地 PDF”。
3. 平台验证 50 MiB 上限和 `%PDF-` 文件头，计算 SHA-256，并按标准化型号建立索引。
4. 点击本地资料卡片，在同一资料阅读器中查看原文、搜索文本、跳转章节和导出证据。
5. 不再需要时使用资料卡片上的“删除”；删除只影响该浏览器中的这份本地副本。

## 数据和恢复边界

- 单个 PDF 最大 50 MiB，最多保存 200 份，总量最大 250 MiB。
- 相同型号和相同 SHA-256 的文件不会重复保存。
- 浏览器清理站点数据、隐私模式退出或浏览器存储回收会移除本地 PDF；原始文件仍应由用户自行备份。
- 当前不会把本地 PDF 放入普通项目 JSON 导出，避免意外产生超大归档或携带受版权保护的文件。
- 扫描版 PDF 可以保留和阅读，但没有文本层时不能进行可靠全文搜索或章节识别。
- 聚合平台资料显示为“用户本地文件”，不会被标记为厂商官方资料。

嘉立创等站点的自动后台抓取容易受到访问控制、WAF 和授权条款影响。EmbedKit 只在获得稳定、授权、版本化接口后启用对应在线适配器；在此之前，本地导入是可重复且不伪造来源的降级路径。
