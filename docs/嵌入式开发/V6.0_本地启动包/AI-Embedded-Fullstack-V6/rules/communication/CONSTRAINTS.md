# 通信总线、网络连接与协议具体约束

## 适用范围与输入

适用于 UART、I²C、SPI、CAN/CAN FD、USB 等板级通信，以及 TCP/UDP/WebSocket、连接状态机和应用协议。输入包括电气/物理层、控制器/驱动能力、速率/时序、帧/协议版本、最大长度、拓扑、端点、超时/重试、安全和兼容要求。

## 总线约束

- UART：明确波特率、数据位、校验、停止位、电平、流控、最大帧和空闲判帧；接收覆盖半包、粘包、溢出、编码错误和断线恢复。
- I²C：地址模式、速率、上拉/总线电容、clock stretching、多主、NACK/仲裁/总线挂死和恢复有项目依据；禁止无限等待 BUSY。
- SPI：模式、位序、字长、片选极性/时序、最高时钟和多设备共享规则明确；DMA 完成前片选/缓冲不得失效。
- CAN：经典/CAN FD、ID、位时序、采样点、终端、过滤、错误计数、bus-off 和恢复策略来自网络设计；安全帧不得无策略丢弃。

## 网络与连接状态

TCP 处理流而非消息边界，发送/接收循环处理短写短读、断开、超时和背压。UDP 明确丢包、乱序、重复、截断和最大报文策略。WebSocket 验证握手、帧长度、分片、控制帧、掩码、关闭和心跳。客户端/服务器限制连接数、缓冲、速率和空闲时间。

连接状态机集中管理解析、连接、认证、心跳、重连、发送队列和关闭；重试有限并退避。DNS、证书、代理、接口和目标来自配置，禁止隐式访问未授权目标。

## 协议、诊断与安全

应用协议先校验边界再访问字段，明确版本、命令、序列号、大小端、单位、校验、ACK/幂等、重复处理和向后兼容。原始帧、解析结果和业务事件使用时间戳/方向/会话 ID 关联；敏感字段脱敏。

协议测试包含合法、边界、截断、超长、错误校验、未知版本/命令、重复、乱序、超时、队列满、断线重连和高吞吐。Fuzz 输入必须有大小、时间和资源上限。

## 验收、证据与失败处理

必需证据：配置、原始抓包/逻辑分析、驱动日志、状态迁移、错误计数和恢复测试。只看到应用日志不能证明物理层或对端收到；只抓到一帧不能证明持续吞吐和恢复。

电气不符、总线持续错误、无界缓冲/重试、协议越界、目标未授权或安全消息丢失时阻断相应连接/发布。通信失效不得阻止本地关键控制进入安全状态。
