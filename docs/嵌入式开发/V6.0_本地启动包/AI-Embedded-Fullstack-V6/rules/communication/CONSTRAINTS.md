# 通信、网络与协议工程详细约束

## 适用范围与链路合同

适用于 UART、I²C、SPI、CAN、USB、BLE/无线、TCP/UDP/WebSocket 和应用协议。开始前建立物理/链路/传输/应用分层合同：两端、方向、速率/模式、地址、帧、端序、单位、超时、重试、并发、安全、版本和断开恢复；未确认值保持 `UNKNOWN`。

## 串行与板级总线

- UART 明确电平标准、波特率、数据/停止/校验、流控、空闲定义和误码处理；TTL、RS-232、RS-485 不得仅称“串口”。
- RS-485 明确终端/偏置、DE 时序、半双工仲裁和回声；发送完成以移位寄存器/硬件事件为准，不只看软件 FIFO 空。
- I²C 明确地址宽度、速率、上拉、电容、重复起始、clock stretching、NACK/仲裁丢失和卡总线恢复。
- SPI 明确 mode、位序、字宽、CS 建立/保持、事务边界和多从机冲突；禁止只按频率相同判断兼容。
- CAN 明确 Classic/FD、位时序、采样点、终端、ID/掩码、DLC、bus-off 和恢复；错误帧与应用 NACK 分开。

## 网络端点与会话

- TCP 明确客户端/服务器、连接超时、keepalive、半关闭、重连和应用帧边界；一次 `recv` 不等于一帧。
- UDP 明确最大报文、丢失/重复/乱序、来源校验和应用确认；不得假定可靠或按发送顺序到达。
- WebSocket 明确 URL/TLS、子协议、文本/二进制、fragment、ping/pong、关闭码和重连；浏览器与 Local Agent 能力边界清晰。
- DNS、代理、IPv4/IPv6、接口选择和网络变化有错误分类；禁止隐式访问未授权内网目标。
- 端点输入校验 scheme、主机、端口和授权范围，禁止字符串拼 Shell；证书验证不能为调试长期关闭。

## 帧设计、解析与编码

- 协议表记录帧头、版本、类型、长度含义、序号、标志、字段偏移、端序、符号、缩放、单位、校验和兼容策略。
- 解析顺序为同步→版本→长度上限→完整帧→校验→命令/字段范围；每次字段读取前检查剩余长度。
- 流解析处理半包、粘包、噪声、超长声明、坏校验、超时、重复、乱序和连续坏帧，并在有界字节/时间内重同步。
- 禁止线数据强转本地结构体；编码前检查容量和整数溢出，只发送实际构造长度。
- CRC 参数必须明确多项式、初值、反射、异或、覆盖范围和测试向量；“CRC16”不足以唯一确定算法。

## 状态机、请求响应与可靠性

- 连接、握手、鉴权、空闲、请求、等待、重连和关闭使用集中状态机；每状态定义事件、超时、非法输入和退出清理。
- 请求有事务 ID/序号、最大并发、迟到响应处理和幂等语义；超时重试不得重复执行非幂等命令。
- 重试有次数、退避、总时限和熔断/降级；无限重连不得占满 CPU、网络或日志。
- 心跳区分链路活性和业务健康，丢失阈值来自项目要求；通信失效不得阻塞本地安全功能。

## 缓冲、吞吐与背压

- 接收/发送缓冲和队列记录容量来源、峰值速率、处理时间、满策略和计数器；禁止无限增长。
- 高吞吐覆盖环形回绕、DMA、分包、消费者滞后和突发；背压策略按链路能力执行，不得静默丢关键帧。
- 日志和 UI 展示设置条数/大小/虚拟化上限，采集与显示解耦；界面卡顿不能阻塞接收线程。
- 多会话隔离状态、缓冲、统计和关闭；端口/套接字释放后才允许可靠重连。

## 安全、隐私与命令执行

- 认证、授权、完整性、机密性和防重放按威胁模型实现；解析合法的帧仍需检查当前状态和命令权限。
- 密钥/令牌/证书不进日志和导出；抓包分享前脱敏。TLS 错误必须可诊断但不得自动降级明文。
- 远程写配置、升级、复位或执行器命令需更高授权、目标确认、审计和失败安全状态。
- 模糊/恶意输入设长度、速率和计算上限，异常日志限频，防止内存/CPU/存储耗尽。

## 测试、验收、抓包与证据

- 测试覆盖有效、边界、坏长度/校验、半包/粘包、重复/乱序、超时、断线、对端重启、队列满和版本兼容。
- 使用独立编码器/解析器或权威向量交叉验证，避免同一错误实现在收发两端自洽。
- 物理总线用逻辑分析仪/示波器，网络用 pcap，关联软件日志和同一事务/时间；模拟器通过不等于真实链路通过。
- 证据包括协议版本/来源、配置、原始帧/抓包、设备/固件身份、错误计数、恢复时间和测试结果。缺真实设备/权限时明确 `NOT_RUN/UNAVAILABLE`，禁止宣称端到端 PASS。
