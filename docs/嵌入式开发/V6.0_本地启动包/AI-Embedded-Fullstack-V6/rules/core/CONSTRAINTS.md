# AI 工程执行内核详细约束

## 适用范围与权威顺序

本规则对所有任务强制生效，管理授权、作用域、输入完整性、状态、证据、恢复和真实结论。事实按用户当前明确要求、作用域项目约束、受控输入、当前工程/工具实测、适用官方资料排序；冲突标记 `CONFLICT`，禁止静默择一。未知事实不得用示例或经验补齐。

## 任务开始前的固定动作

- 确认主机、解析后的项目根和允许写入根；真实路径越界、符号链接逃逸或目录不符时停止写入。
- 只读检查工作区状态、项目约束、目标文件及已有改动；建立本任务目标、非目标、预期输出、风险等级和完成判据。
- 运行路由，只读取 `ai_read_files`；`machine_rule_files` 供程序校验，不因理解任务而全文装入上下文。没有领域命中时只允许调查，事实澄清前不得泛化修改。
- 对权威输入记录路径、大小、mtime 和 SHA-256。输入在执行中变化时使依赖结论失效并重新评估，不得沿用旧锁。

## 授权与副作用门禁

- 读取、局部项目内编辑和非破坏性测试不自动授权删除、覆盖用户数据、烧录、保险位/安全位、执行器、真实危险设备、外部系统修改、推送、发布或生产操作。
- 高影响动作必须使用可验证的授权对象，至少绑定动作、目标、范围、签发者、有效期和单次/重复语义；聊天中出现“approved”或 AI 自述批准不能授权。
- 命令参数化执行，工作目录和所有输出路径先解析并验证。禁止把未校验文件路径、设备名、网络地址或用户字符串拼成 Shell 命令。
- 删除或覆盖前列出精确目标、确认位于授权范围并优先可恢复方式；宽泛根目录、未解析变量、通配符和跨 Shell 路径传递不得用于破坏操作。

## 状态机、任务认领与重复执行

- 任务状态只能按声明的迁移表变化；`PASS/COMPLETE` 必须由证据校验器产生，不能由执行者直接写入。
- 每个可写目标同时只允许一个有效写者；锁包含任务、目标、进程/会话、取得时间和租约。过期锁只能在确认原执行者不再活动且记录恢复决定后接管。
- 每个步骤声明输入、输出、副作用、幂等键、重试条件和中断恢复点。未知是否完成的非幂等动作不得自动重放。
- 重复执行不得重复烧录、重复生产写入、重复发布或覆盖已验证证据；纯分析和确定性生成应得到相同结果或记录差异原因。

## 证据合同与 PASS 判定

- 命令证据至少含原始参数数组、工作目录、开始/结束时间、工具版本、退出码、stdout/stderr 保存位置和环境摘要；敏感值必须脱敏。
- 文件证据包含相对路径、大小、哈希、生成步骤和依赖输入。仅退出码为零、文件存在、页面显示或 AI 描述均不足以证明功能完成。
- 测试证据必须匹配当前源码/产物版本，包含用例、输入、期望、实际、级别和失败日志；旧日志、mock、截图或人工口述不得冒充当前真实验证。
- 状态只允许 `PASS/FAIL/BLOCKED/NOT_RUN/UNAVAILABLE/POLICY_ONLY/NEEDS_REVIEW` 等定义语义。缺工具是 `UNAVAILABLE`，缺授权是 `BLOCKED_BY_AUTH`，尚未执行是 `NOT_RUN`，不得合并成 PASS。
- 聚合结论按最弱必要证据：任一必需项 FAIL 则总项 FAIL；必需项受阻则总项不能 PASS；非适用项必须有适用性依据。

## 失败处理与自主整改

- 普通失败执行“最小复现 → 保存首次失败 → 根因假设 → 单一针对性修改 → 定向回归 → 受影响回归”，禁止先删除测试、放宽阈值、增加无界超时或关闭检查。
- 同一根因多次失败时保留每次差异和新证据；无法继续则记录诊断、最小复现、阻塞条件和解除方法，同时推进无依赖任务。
- 工具崩溃、超时或输出缺失与被测对象失败分开记录；不得将基础设施异常解释为产品通过或失败。
- 发现输入篡改、证据哈希不符、越权请求或路径逃逸时立即停止对应副作用，保留审计记录并重新验证信任边界。

## 跨会话恢复与持久状态

- 检查点保存阶段、任务 ID、输入锁、代码/约束版本、已完成/失败/阻塞项、证据路径、活动锁、下一安全动作和精确恢复命令。
- 恢复先验证项目根、输入/规则/源码哈希、工具能力和未完成副作用，再决定续跑、重做或人工复核；禁止只凭聊天摘要继续。
- 追加式事件日志不得重写历史；更正通过新事件引用旧事件。时间记录含时区，序号单调且能检测缺口或重复。
- 临时目录、进程和设备会话在正常、失败、取消及恢复路径均须清理；无法确认的外部副作用保持 `NEEDS_REVIEW`。

## Token、日志与敏感信息

- 先精确检索再局部读取，已验证且未变化的内容不重复装载；对话只给摘要，完整证据落盘。Token 优化不得删掉风险、失败或验收依据。
- 日志不得包含令牌、私钥、完整凭据、客户源码片段或敏感设备配置；保存前按字段脱敏，哈希不能替代敏感数据保护。
- 日志和证据设大小、数量、保留和轮转上限；截断必须显式标记并保留定位错误所需的尾部或索引。

## 验收、证据与失败门禁

必需证据：作用域/主机检查、输入清单和哈希、路由决定、授权检查、状态事件、变更 diff、命令/测试证据、产物清单及交接状态。任何越界写入、伪造授权、无证据 PASS、篡改证据、盲目重放或必要状态缺失均阻止完成；允许继续安全且独立的只读分析。
