# 可靠性、EMC、环境与寿命具体约束

## 适用范围与输入

适用于看门狗、复位恢复、故障注入、供电扰动、温湿度、振动、ESD/EFT/浪涌、EMI/EMS、存储/Flash 寿命、长期运行和可靠性验证。具体等级、波形、限值和样本量必须来自产品市场、适用标准和批准计划，通用包不得伪造。

## 设计与分析动作

1. 从使用环境、任务周期、寿命目标和失效后果建立可靠性需求、应力剖面和验证计划。
2. 分析关键器件/接口/状态的失效模式、检测、隔离、安全状态、恢复和残余风险；覆盖单点故障与共因因素。
3. 看门狗、棕断、复位原因、错误计数和健康监测具有真实工作证明，不以“能复位”替代根因恢复。
4. Flash/NVM、继电器、连接器、电池、风扇等寿命按实际频率、温度、降额和数据手册计算；缺输入输出 UNKNOWN。

## 环境与 EMC 验证

测试前锁定硬件/BOM/固件/线束/外壳/工作模式、监测点、判据和恢复方式。预检、施加应力、实时监测、应力后功能/数据检查和样品处置均记录。EMC 问题不得仅通过关闭功能或降低性能规避，除非这是批准的降级要求。

ESD/EFT/浪涌和供电跌落测试区分无影响、暂时降级/自恢复、人工恢复、数据丢失和损坏。复位后必须验证关键状态、持久数据、通信和安全输出，不把重启本身判为通过。

长期/压力测试设置持续时间、负载、日志轮转、资源监测、故障判据和停止条件。内存/句柄/队列/文件系统/温度趋势需要量化，不能只看最终仍在运行。

## 验收、证据与失败处理

必需证据：应力/标准来源、样品与版本、仪器校准、配置/布置、原始波形/日志、实时和应力后结果、失效分析。模拟、预检和认证实验室结果分级记录。

发生安全风险、不可恢复损坏、数据破坏、热失控或应力超出批准范围时立即停止。失败样品隔离并保留现场，禁止反复重测直到偶然通过；修复后用相同条件复现、回归并评估新失效模式。
