# 适配器、插件与扩展生态详细约束

## 适用范围与设计目标

适用于芯片、RTOS、IDE、工具链、MAP/ELF、EDA、协议、设备和规则扩展。扩展只能通过稳定接口增加能力，不能把工程特例写入公共模型/页面，也不能因单个插件失败破坏核心或其他扩展。

## 扩展清单与能力声明

- 每个扩展有稳定 ID、名称、版本、接口版本、供应者、适用平台/格式/版本、入口、权限、依赖和许可证。
- 能力声明使用结构化枚举，区分 `probe/read/parse/build/write/device` 等级；未声明或探测失败的能力不得调用。
- 声明测试样本、已验证版本、未知版本降级和输出证据；“兼容所有版本”没有测试矩阵不得接受。
- 扩展包有内容清单和哈希/签名策略；加载路径规范化且限制在受信根，禁止任意路径动态执行。

## 版本化接口与数据模型

- API/消息/schema 有显式版本和兼容范围；破坏性变更提升主版本并提供迁移/兼容读取。
- 输入输出使用公共稳定模型，保留原始证据、来源、位置、置信度和未知字段；插件私有对象不得泄漏到核心持久化。
- 错误使用结构化代码区分不支持、输入损坏、工具缺失、许可、超时、权限和内部故障，禁止只返回字符串“失败”。
- ID 稳定且不依赖显示名/路径；序列化限制大小、深度、条数和编码，未知字段安全保留或忽略。

## 生命周期、隔离与资源控制

- 生命周期包含发现、验证、加载、初始化、探测、调用、取消、关闭和卸载；任一步失败执行对称清理。
- 插件调用有超时、取消、内存/输出/进程上限和日志轮转；组件卸载后不得继续回调或占用设备/文件。
- 单插件异常、崩溃或坏输出被隔离并熔断，核心保持可用；重复重启有上限，不产生崩溃循环。
- 并发调用明确线程安全、实例/会话隔离和共享工具锁；同一设备/工程写操作不能被多个扩展同时执行。

## 权限与安全边界

- 清单声明文件读写根、网络目标、设备、进程和凭据需求；默认拒绝，运行时按任务最小授权。
- 插件不能绕过核心授权执行 Shell、烧录、删除、发布或真实设备动作；用户输入不得直接形成命令或路径。
- 机密通过受控引用/凭据服务传递，不写清单、日志或普通配置；第三方插件不能默认访问项目全部源码。
- Web 插件和 Local Agent 插件边界明确；浏览器能力不得伪装拥有串口、原始网络或进程权限。

## Probe、选择与冲突解决

- `probe` 只读且返回工具路径/版本/能力/限制/证据，不执行构建、写文件或控制设备。
- 多适配器匹配时按明确优先级、特征强度和用户/项目选择决策；禁止按注册顺序静默选中。
- 检测结果包含置信度和命中特征；无法识别降级为通用源码/二进制/原始数据，不猜成最相似平台。
- 两扩展声明同 ID、命令或格式且版本不兼容时阻止加载并报告冲突，不能后加载覆盖前者。

## 解析器与写适配器要求

- 解析器保留原始输入哈希、偏移/行号、未识别记录和诊断；损坏输入给部分结果时必须标覆盖率/不完整，不能 PASS。
- 测试有效、边界、截断、超长、未知版本、恶意嵌套和多编码；设置 CPU/内存上限，防止解析炸弹。
- 写适配器必须显式能力、目标版本和授权，只在临时/隔离副本生成；保存后由独立读取路径回读比较对象和语义。
- 不能保证无损转换时明确 `LOSSY/PLAN_ONLY`，列出丢失对象；禁止覆盖唯一原生文件。

## 工具、设备与失败降级

- 外部工具调用记录可执行文件身份/版本、参数数组、工作目录、退出码、日志和产物；仅检测到程序文件不代表许可证/功能可用。
- 设备适配器验证设备 ID、能力、固件和会话所有权，关闭/取消释放资源；不得默认选择第一个串口/探头。
- 工具缺失标 `UNAVAILABLE`，版本不支持标 `UNSUPPORTED`，权限缺失标 `BLOCKED_BY_AUTH`；不得用 mock 输出替代真实结果。
- 插件降级不能影响不相关纯浏览器/核心能力，UI 清楚显示当前提供者、能力边界和恢复方式。

## 测试矩阵、发布与兼容

- 每个扩展至少包含契约测试、有效/损坏/未知样本、取消/超时/资源上限、并发、旧数据兼容和故障隔离。
- 测试矩阵覆盖声明的代表版本，不得只用当前用户工程；样本记录来源、许可和哈希。
- 发布前验证清单/schema、依赖、签名/哈希、核心最低/最高版本、安装/卸载/回滚和迁移；旧扩展失败不得阻止核心启动。
- 远程更新、市场安装或外部发布需要独立授权；本地测试成功不自动授权分发。

## 验收、证据与失败门禁

证据包括清单、接口/schema、权限声明、probe、样本矩阵、契约/隔离/资源测试、回读比较、兼容和发布包哈希。存在未声明权限、任意代码/路径执行、坏插件拖垮核心、未知格式被猜测、写回未验证或 mock 冒充真实工具时禁止扩展发布和启用写能力。
