# 安全、发布与现场维护具体约束

## 适用范围与输入

安全功能、联网、身份/密钥、固件升级、控制执行器、认证、正式发布和现场维护均适用。输入包括资产/威胁、风险与安全状态、适用法规市场、信任根、版本/兼容矩阵、升级回退策略、漏洞状态和批准责任。未知产品标准或阈值不得由通用模板猜测。

## 安全与失效安全动作

1. 建立资产、入口、信任边界、攻击者能力、威胁、缓解和残余风险；区分产品安全、功能安全与一般可靠性。
2. 外部输入执行认证/授权、长度和格式校验、防重放/速率限制及最小错误泄露；默认拒绝未知高权限命令。
3. 密钥不硬编码、不写日志；定义生成、注入、存储、使用、轮换、吊销和销毁。随机数和密码算法必须来自已验证平台能力。
4. 安全启动/OTA 核对镜像身份、签名、版本、防降级、原子切换、断电恢复和回退；传输加密不能替代镜像验证。
5. 安全关键控制明确故障默认状态、独立本地保护、响应时间、复位/通信失效行为、故障注入和人工责任。云端在线不能作为本地安全前提。

## 发布门禁

候选发布锁定源码、构建环境、依赖/SBOM、硬件/BOM、固件/Bootloader、协议/NVM/标定、测试配置、工具版本和产物哈希。检查许可证、已知漏洞、调试入口、测试密钥、默认凭据、日志敏感信息及发布配置。

发布级别分离：候选生成、工具验证、集成验证、实机验证和正式批准。AI 无权从测试通过自行升级到正式发布；Git push、公开发布、生产配置和签名分别授权。

## 现场维护与恢复

定义升级前检查、兼容判定、备份、进度、超时、断电恢复、回退、失败隔离、审计和用户可见状态。现场日志要脱敏、限量并关联设备/版本；远程操作使用目标身份和最小权限，禁止广播式未确认控制。

漏洞/事故记录影响范围、临时缓解、修复、回归、通知和密钥/版本处置。停产与退市仍保留恢复材料、兼容信息和追溯周期。

## 验收、证据与失败处理

必需证据：风险/威胁记录、安全合同、扫描/测试原始结果、镜像与 SBOM 哈希、兼容/回退验证、批准来源。安全测试未执行、残余高风险未接受、签名身份不明、回退未验证或秘密泄漏时阻断对应发布。

无法访问设备、签名服务、认证机构或批准人时标记 `BLOCKED_BY_AUTH/NOT_RUN`，不得使用测试密钥、模拟签名或 AI 批准代替。
