# 构建系统、工具链与固件产物具体约束

## 适用范围与输入

适用于 Keil/IAR/GCC/Clang 等工程识别，CMake/Make/Ninja 辅助构建，链接脚本、ELF/MAP/AXF、BIN、Intel HEX、符号、固件大小、崩溃地址和版本比较。优先识别并使用现有工程入口，不把转换为新构建系统作为前置条件。

## 工程与工具链识别

记录工程文件、目标/配置、编译器及版本、SDK、宏、包含路径、源文件集合、链接脚本、库、后处理和产物位置。不同配置必须独立标识；Debug 成功不能证明 Release 或生产目标成功。

命令使用结构化参数，固定工作目录和环境；构建默认不执行 clean/rebuild 删除旧产物。工具、许可证或专有库不可用时标记 UNAVAILABLE，不用其他编译器的成功替代目标工具链。

## 产物与内存诊断

- ELF/AXF：核对架构、入口、段、符号、调试信息和 build ID；符号解释必须匹配当前固件哈希。
- MAP：解析 Flash/RAM、段/对象/符号贡献、堆栈保留、重叠/溢出和未使用大对象；解析器按工具链适配，未知格式安全降级。
- BIN：记录起始地址/加载关系不能仅从裸 BIN 猜测；需要链接/清单提供地址。
- Intel HEX：严格校验记录长度、类型、地址扩展、校验和、重叠和范围；损坏记录不得静默忽略。
- 多产物比较使用相同目标/配置/工具链和可比规则，区分时间戳等非功能差异与实际段/符号变化。

## 可复现与版本嵌入

记录源码提交/脏哈希、依赖/工具版本、命令、环境关键变量和生成器。构建产物应有可查询的产品/硬件兼容/固件版本或外部不可变清单；禁止仅凭文件名判断身份。

可复现性测试在隔离目录用相同锁定输入重复构建，比较规范化后的产物。若工具写入时间戳、路径或随机值，应明确不可复现字段及其来源，不能伪称字节完全一致。

## 验收、证据与失败处理

必需证据：工具探针、实际命令/工作目录/环境摘要、完整日志、目标配置、产物清单及哈希、MAP/ELF 解析覆盖率和未知项。退出码 0 但预期产物缺失、产物未更新或目标错误均失败。

链接溢出、段地址越界、HEX 校验失败、产物身份不明或符号不匹配时禁止下载/发布。解析器遇到未知工具格式时保留原始文件，输出 UNKNOWN 字段和已覆盖范围，不得套用 GCC/Keil/IAR 的错误规则。
