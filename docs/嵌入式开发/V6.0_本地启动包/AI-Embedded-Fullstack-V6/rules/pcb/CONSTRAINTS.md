# PCB 设计、验证与制造输出具体约束

## 适用范围与输入

输入必须包括原理图/网表、BOM 与封装、板框/安装孔/禁布区、层叠/铜厚、板厂线宽线距孔径能力、阻抗目标、电流/温升、结构高度、EMC/RF/模拟/安全要求和原生可编辑 PCB。未知板厂或材料条件不得用通用数字替代。

## 规则推导与布局动作

1. 核对网表、封装、Pin1/极性、器件数量、板框、孔和结构版本；差异先回到权威源解决。
2. 从真实电流、压降、阻抗、隔离和制造能力推导 NetClass、差分、过孔、铜皮和安全规则，记录公式、单位、来源与裕量。
3. 先固定连接器、安装孔、天线、传感器、隔离区和结构关键件；再放电源、时钟、MCU、存储、模拟和普通器件。
4. 去耦靠近对应电源脚并有短回流；开关电源最小化高 di/dt 回路；模拟参考、晶振、RF 和高阻节点按器件资料处理。
5. 布线保持连续回流，避免无依据跨分割；关键电源、差分、高速、时钟、模拟和安全网络按优先级完成。铺铜后重新检查孤岛、颈缩、热焊盘和回流路径。

## 自动化与工具边界

自动布局/布线必须由实际可用引擎执行，记录对象级操作并重新打开原生文件核查。没有引擎时状态为 `CAPABILITY_GAP/PLAN_ONLY`，不得生成 PNG、Gerber 或空 PCB 冒充可编辑布线成果。跨 EDA 转换是独立兼容测试，不默认无损。

KiCad/AD 适配器须先 `probe` 版本和能力；写回只在隔离副本、明确授权和格式兼容验证后进行。每次编辑保存前后哈希、对象计数、未布线数和网表一致性。

## DRC 与制造输出

- 真实运行 DRC，保留原始报告；错误逐项关联网络、坐标、规则和整改，复跑至合同要求。waiver 必须有工程理由和责任批准。
- 制造包至少核对 Gerber 层映射、钻孔/槽、板框、阻焊/钢网、坐标原点、单位、镜像、PnP、BOM、装配图和版本标识。
- 输出后使用独立查看/回读检查层、孔和坐标，并生成逐文件哈希清单。文件存在不代表可生产。

## 验收等级、证据与失败处理

只允许报告实际达到的级别：`PLAN_ONLY / EDITABLE_LAYOUT / ROUTED / DRC_VERIFIED / FAB_FILES_CHECKED / PHYSICALLY_TESTED`。必需证据包括原生 PCB、输入版本、自动操作日志、未布线计数、DRC 报告、制造清单及哈希、未验证的热/RF/EMC/结构项。

网表不一致、关键规则未知、DRC 关键错误、未布线或输出回读失败时禁止制造放行。缺 EDA 时保持 `BLOCKED/NOT_RUN`，但可继续规则推导和静态审查。
