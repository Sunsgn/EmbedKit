# PCB 设计、验证与制造输出详细约束

## 适用范围、输入、版本与工具边界

开始前取得匹配版本的原理图/网表、BOM/封装、板框/孔/禁布区、层叠/铜厚、板厂能力、阻抗、电流、结构高度、安规/EMC/RF/模拟要求和原生 PCB。任何关键版本不一致先解决，禁止在错误网表上继续布局。

KiCad/AD 适配器必须实测当前版本、许可证、格式读写和 DRC 能力。没有真实布局/布线引擎时状态只能是 `PLAN_ONLY/CAPABILITY_GAP`，禁止用图片、Gerber、空 PCB 或文本坐标冒充可编辑设计。

## 规则推导与约束录入

- 从板厂最小线宽/间距/孔环、层叠、铜厚和阻抗能力建立规则基线；禁止直接套用另一板厂或样例规则。
- 电源线宽/铜皮/过孔根据最坏电流、允许压降、温升、环境和铜厚推导；说明公式/工具、单位、输入和裕量。
- 差分阻抗、间距、参考层和长度目标来自接口/器件/层叠；EDA 名义值必须与板厂场解或确认值对应。
- 爬电/电气间隙按适用标准和项目参数确定；开槽、涂覆和海拔修正须有依据，未知时阻止安全网络放行。
- NetClass、差分、长度、过孔、禁布、区域和例外写入原生规则；waiver 不得仅存在于聊天或截图。

## 数值规则的最低计算合同

- 每条数值规则必须记录 `对象/网络 → 输入值及单位 → 来源版本/页码 → 公式或工具及版本 → 最坏结果 → 设计裕量 → 写入 EDA 的值 → 验证证据`。缺少任一关键输入时该规则保持 `UNKNOWN`，不得填“常用值”。
- 电源路径必须从负载最坏电流、允许压降、铜厚、外层/内层、温升、环境和并行路径推导；同时核对线段、焊盘颈缩、过孔、连接器和保险/开关器件。通过加宽主干但保留未计算的局部颈缩不能判 PASS。
- 大电流过孔必须用目标板厂成品孔径/孔铜和适用模型计算单孔电阻、损耗与温升，并考虑过孔间热耦合和电流分配；`总能力 = 单孔额定 × 数量` 只能作为未经验证的上界，不能作为放行依据。
- 高速约束先依据发送器上升/下降时间、互连传播延迟和拓扑判断是否需要传输线处理，再依据当前层叠场求解或板厂阻抗表确定几何；禁止仅按时钟频率或接口名称选规则。
- 差分对必须同时给出单端/差分阻抗、线宽、间距、参考层、铜厚、介质厚度/介电常数、允许偏差、对内偏斜和层换结构。EDA 几何与板厂确认值不一致时，以重新求解和确认结果为准，禁止只改阻抗标签。
- 安规间距必须保存适用标准版本、工作/瞬态电压、材料组、污染等级、海拔、绝缘类别及涂覆/开槽条件；无法确定适用条件时只允许物理隔离候选方案，不得标为安规通过。

## 封装、板框与机械基准

- 同步前核对引用、封装名、Pad 编号、Pin1/极性、底部焊盘、NPTH/PTH、器件数量和网络；禁止仅看飞线数量判断一致。
- 板框闭合且无重复/自交，尺寸、圆角、槽、安装孔、定位孔、拼板边和连接器基准与结构版本一致。
- 对高度、外壳、按键、显示、天线、传感器、光学、散热器和线束建立带来源的 keepout/courtyard；3D 仅辅助，关键尺寸仍需工程图核对。
- 库更新后比较 Pad 位置/尺寸/层/孔/阻焊/钢网和庭院，禁止静默接受全局库变化。

## 布局顺序与具体要求

- 先固定板框、孔、连接器、天线、传感器、隔离区和结构关键件；再放电源入口/转换、时钟、处理器/存储、模拟和普通器件。
- 去耦对应到具体电源脚，靠近且回路短，电源/地过孔不形成共享长颈；不同容量的作用和放置遵循器件资料。
- 开关电源最小化输入开关、续流和输出高 di/dt 回路；SW 节点铜面积受控并远离反馈、时钟、模拟和天线。
- 晶振回路短、对称、参考连续且远离高速/开关节点；模拟参考、高阻和小信号有明确回流及隔离策略。
- 发热器件、温敏器件、气流、壳体接触和铜扩散协同；布局完成后做密度、装配/返修、测试探针和可视性审查。

## 布线、回流、过孔与平面

- 关键电源、时钟、差分、高速、模拟、安全网络优先；每条关键线明确参考层和回流路径，禁止无依据跨平面分割。
- 换层时为高速回流提供就近缝合路径；差分对应过孔和参考变化保持一致。长度匹配只在功能要求范围内，不为“整齐”制造蛇形耦合。
- 电源/地平面检查孤岛、狭颈、回流绕行、热焊盘和铜到板边；铺铜后必须重新 DRC 和网络连通检查。
- 大电流过孔阵列核对单孔能力、孔环、制造公差和电流分配；禁止按过孔数量简单线性放大而不考虑热/颈缩。
- 测试点、编程口和产测焊盘满足工装间距、接触、回流和可访问性，不破坏信号质量。

## 自动化编辑与可恢复性

- 自动操作以对象 ID/网络/坐标记录每次移动、旋转、换层、布线和规则变更；保存前后哈希、对象计数、未布线数和网表一致性。
- 写回只在可恢复副本执行；保存后关闭并重新打开原生工程，确认层、网络、规则和对象未丢失。跨 EDA 转换默认有损，必须单独兼容验证。
- 自动布线不能越过锁定对象、keepout、差分/长度或安全规则；失败时保留未完成网络，禁止用删除飞线或改网络名制造“已完成”。

## DRC、SI/PI/热与整改

- 真实运行 DRC，保留工具版本、规则文件、原始报告和坐标；逐项分类为真实缺陷、已批准例外或工具限制，整改后复跑。
- `0 DRC` 只证明已配置规则，不能证明规则完整。独立核对未布线、短路、网络断开、板框、孔、丝印、阻焊和制造能力。
- 高速/电源/热风险按项目要求进行 SI/PI/热分析或样机测量；未执行标 `NOT_RUN`，禁止由 DRC 推导性能通过。

## 制造数据生成与回读

- 制造包明确 Gerber/ODB++ 层映射、钻孔/槽、板框、阻焊、钢网、坐标原点、单位、镜像、PnP、BOM、装配图、阻抗表和版本标识。
- 生成后用独立查看器或回读解析核对每层、孔、槽、外形、极性、原点和器件坐标；文件存在不能证明可生产。
- 输出目录不得混入旧版本；生成逐文件大小/哈希清单并与原生设计版本绑定。任何重新生成都使旧签核失效。

## 验收等级、证据与失败门禁

只允许报告实际等级：`PLAN_ONLY / EDITABLE_LAYOUT / ROUTED / DRC_VERIFIED / FAB_FILES_CHECKED / PHYSICALLY_TESTED`。证据包括输入版本、原生 PCB、规则推导、操作日志、未布线数、DRC、回读结果、制造清单/哈希及未验证 SI/PI/热/EMC/结构项。网表不一致、关键规则未知、关键 DRC、未布线或输出回读失败时禁止制造放行。
