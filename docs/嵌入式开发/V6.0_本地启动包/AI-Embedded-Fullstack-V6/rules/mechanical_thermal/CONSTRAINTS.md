# 结构、热设计与装配接口具体约束

## 适用范围与输入

适用于外壳、PCB/连接器/按键/显示/传感器安装、尺寸公差、热路径、防护、材料、紧固、线束、振动和装配。输入包括工业/结构需求、三维/二维图、PCB 机械数据、器件高度/禁布、功耗/温升、材料特性、制造工艺、环境和维护方式。

## 机械接口与公差

建立统一坐标、单位和版本；板框、孔位、连接器、天线、传感开口、按键、显示和外壳配合双向核对。尺寸链列出名义值、公差、基准、装配间隙/压缩和最坏组合；不得只用名义尺寸判断可装配。

关键器件高度、禁布、弯折、线束转弯、工具空间、螺钉/柱、绝缘和爬电要求进入 PCB/结构约束。连接器插拔、维护、更换和防呆在实际装配路径验证。不同 CAD/EDA 格式转换后重新核对坐标、比例、层和孔。

## 热与材料

热分析至少包含环境范围、器件损耗、热源分布、导热/对流/辐射路径、接触热阻、界面材料、外壳/风道和降额。仿真记录模型、网格、材料、边界和假设；必须用样机温度测量校核才能升级为物理验证。

材料选择记录温度、阻燃、UV/化学、吸湿、导电/绝缘、腐蚀和法规适用性。异种金属、涂覆、密封、胶粘和导热材料考虑老化、返修及供应替代影响。

## 防护、振动与装配

IP/密封目标必须来自产品要求和适用标准；密封圈压缩、接缝、透气、排水和连接器是系统设计，不能凭外观宣称等级。振动/冲击评估 PCB 固定、重件、焊点、连接器锁止、线束和共振；测试配置绑定实际装配。

装配工艺定义顺序、扭矩/锁固、方向、防错、检验点和可返修性。扭矩、胶量、压装等数值来自器件/工艺验证，AI 不生成未经验证生产参数。

## 验收、证据与失败处理

必需证据：版本化结构/PCB 接口、尺寸链、碰撞/间隙检查、热计算/仿真及测量、材料/工艺来源、装配与环境测试。图片或单次试装不能证明公差批量能力。

干涉、最坏公差不足、温度超限、绝缘/密封未知、重件无可靠固定或维护不可达时阻断相应设计/制造。缺样机/环境工具时可输出候选分析，但物理验证为 NOT_RUN。
