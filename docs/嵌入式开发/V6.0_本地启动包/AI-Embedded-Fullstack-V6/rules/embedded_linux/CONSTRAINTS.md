# Embedded Linux、内核与系统镜像详细约束

## 适用范围与基线

适用于 Bootloader、内核、设备树、驱动、rootfs、服务、交叉构建、升级和现场诊断。开始前锁定 SoC/板卡版本、Bootloader、内核树/配置、DTS、工具链、rootfs/包清单、分区和实际镜像哈希；发行版 PC 的行为不得直接外推目标机。

## 启动链与分区

- 描述 ROM→一级/二级 Bootloader→内核→initramfs/rootfs→init/systemd→应用的镜像、地址、验证和失败路径。
- 分区表、擦除块、文件系统、A/B 槽、环境变量和恢复分区来自当前设备权威源；地址未知禁止写入。
- 收集串口全启动日志并用阶段标记定位；无日志区分供电/复位、Boot、内核早期控制台和用户态问题。
- 内核命令行、root 参数、console 和安全选项受版本控制，临时调试参数不得进入发布默认。

## 内核配置与交叉构建

- 记录内核版本/补丁、defconfig、配置片段、架构、交叉工具链和构建命令；`.config` 手工改动需回写受控配置。
- 驱动内建/模块选择基于启动依赖、安全和更新策略；模块 vermagic、符号版本和签名与运行内核匹配。
- 构建输出隔离，保存 Image/zImage、DTB/DTBO、模块、System.map、配置和哈希；宿主机头文件/库不得意外进入目标构建。
- 上游/厂商补丁记录来源、适用版本和冲突解决；不因能编译就认为可长期维护。

## 设备树具体规则

- DTS/DTSI include 和 overlay 的最终展开结果与原理图核对 compatible、reg、interrupt、clocks、resets、pinctrl、GPIO 极性、供电和总线地址。
- `status = "okay"` 前确认硬件存在且资源无冲突；禁止复制参考板节点而不验证板级连接。
- 地址/size-cells、中断父/触发、时钟索引、phandle 和 regulator 依赖由 binding/当前内核文档验证；dtc 无警告不能证明语义正确。
- 编译后反编译/检查实际 DTB，并在目标 `/proc/device-tree` 或等价接口确认运行版本；源码 DTS 不代表设备加载了它。

## 内核驱动与并发

- 遵循 probe/remove、defer、runtime PM、suspend/resume 和错误 unwind；每个获取资源在所有失败路径对称释放。
- MMIO、IRQ、DMA、clock/regulator/reset、GPIO 和 pinctrl 使用内核管理 API；禁止硬编码虚拟地址或绕过资源所有权。
- 用户接口定义 ABI、权限、阻塞/非阻塞、poll、并发、长度和兼容；copy_to/from_user 返回值必须处理。
- 中断顶半短小；线程化 IRQ/workqueue/tasklet 选择符合上下文。锁顺序、睡眠上下文、引用计数和热拔插生命周期需验证。

## Rootfs、服务与持久数据

- rootfs 包和许可证有清单/锁定；删除“无用”组件前检查启动、恢复、调试和许可证脚本依赖。
- 服务声明用户/组、能力、文件权限、依赖、启动超时、重启限制、资源上限和日志轮转；禁止 root 常驻作为默认解决权限问题。
- 只读根、overlay、数据分区和工厂重置边界明确；升级不得覆盖设备身份、密钥、校准或用户数据。
- 配置有 schema/版本/迁移和原子写入；systemd `Restart=always` 不能掩盖崩溃循环。

## 网络与系统安全

- 仅开放需求端口，服务绑定地址、TLS/证书、认证、权限和防火墙规则明确；调试 SSH/Telnet/ADB 不得默认开放发布镜像。
- 内核能力、seccomp/LSM、只读文件系统和最小权限按项目风险使用；设备节点权限不以 `0666` 规避设计。
- SBOM、CVE 和补丁评估绑定具体内核/包版本及配置，记录适用性和缓解；扫描未发现不能证明无漏洞。

## 性能、存储与现场诊断

- 测量启动阶段、CPU、内存、IO、网络和存储，在目标负载下观察 OOM、调度延迟、泄漏和日志增长。
- Flash/eMMC 文件系统考虑掉电、坏块、写放大、只读恢复和 fsck；台式机文件系统测试不能替代目标介质。
- 诊断收集 dmesg/journal、proc/sys/debugfs（授权时）、core/pstore 和版本信息，设置大小/隐私上限；地址解析匹配同版 vmlinux/System.map。

## 更新、回退与验收

- 更新验证镜像身份、硬件、分区和签名，抗断电并支持启动健康确认/回退；内核、DTB、模块和 rootfs 作为兼容集合处理。
- 证据包括启动链、配置/工具链、DTS/binding 核对、实际 DTB、镜像/模块哈希、目标日志、服务/安全、掉电和回退测试。
- 仅 QEMU/容器/宿主测试不能证明板级驱动、时序、DMA、功耗或存储通过；无目标板标 `NOT_RUN`。分区/电压/设备树资源不确定时禁止写镜像或启用硬件。
