# 制造、产测、标定与追溯具体约束

## 适用范围与输入

适用于 DFM/DFA/DFT、BOM/AVL、试产、工装、产测、标定、工厂固件、配置、质量追溯和制造交付。输入包括批准的硬件/PCB/BOM/固件版本、制造能力、工艺和检验规范、测试设备/校准状态、产品标识方案及责任批准。

## DFM、BOM 与工艺动作

1. BOM 每项记录制造料号、规格、封装、生命周期、AVL、替代条件和版本；替代料需重新分析电气、软件、校准、法规和供应风险。
2. 核对 PCB 制造输出、钢网、拼板、工艺边、装配方向、可焊性、可检查性、测试点和返修空间；规则来自实际板厂/产线。
3. 工艺文件记录设备、参数范围、治具/程序版本、关键质量点和异常处置；AI 不生成未经验证的生产参数冒充批准值。
4. 试产记录批次、投入/产出、不良模式、返工和变更；问题进入根因/CAPA，不以平均良率掩盖安全或系统性缺陷。

## 产测、工装与标定

- 产测用例关联硬件、固件、Bootloader、配置和工装版本；覆盖身份、供电、电流、接口、存储、传感/执行器和适用安全功能。
- 工装具备自检、连接防错、超时、急停/安全隔离、资源释放和故障恢复；设备命令不接受未校验字符串。
- 标定记录原始测量、参考标准、单位、算法/系数、范围、温度/环境、设备校准状态、操作时间和产品唯一标识。
- 标定数据有 schema 版本、长度、校验、合法范围、写入确认、回读、掉电保护和迁移/回退；禁止无来源的生产默认值。

## 配置与追溯

每台/批产品可追溯到硬件/BOM、PCB、固件、Bootloader、协议、NVM/标定、产测程序、工装、测试结果和批准。版本兼容矩阵未验证的组合必须阻断，不允许混版无条件放行。

密钥、证书和设备秘密使用最小权限及安全注入流程，日志不得包含完整秘密。公开交付包不保存真实生产凭据。

## 验收、证据与失败处理

必需证据：制造清单哈希、版本兼容矩阵、工艺/工装版本、原始产测/标定结果、设备身份、异常记录和批准来源。生成 Gerber、BOM 或程序不等于量产批准。

缺实际产线、工装、校准设备或授权时，相关状态为 `BLOCKED/NOT_RUN`；可继续静态完整性和兼容检查。测试失败、校准越界、身份重复、追溯断链或混版时隔离受影响对象，不得自动改成 PASS 或进入发布。
