# 安全与权限约束

## 1. 最小权限

默认只允许项目内只读调查、用户要求范围内的局部编辑和非破坏性验证。约束文件不扩大AI工具自身权限，也不代表用户授权了外部系统、网络、硬件或生产环境操作。

## 2. 需单独授权的动作

删除或覆盖重要数据、固件烧录、熔丝/保险位/安全位、量产写入、校准系数永久写入、危险电压或执行器动作、外部账号或云资源修改、Git推送、正式发布和生产切换，均需明确目标、影响、恢复方案和用户授权。

## 3. 本地数据与隐私

源码、原理图、PCB、BOM、固件、日志和设备数据默认本地处理。使用外部AI或网络服务前必须说明上传范围、用途、保留方式和敏感信息处理。日志不得记录密钥、令牌、完整凭据或受保护生产参数。

## 4. 命令与路径

进程调用优先参数化并避免Shell拼接。文件、工作目录、网络目标和设备标识必须校验并限制在用户指定范围。未知状态的非幂等操作不得自动重放。

## 5. 失效安全

涉及电机、加热、高压、大电流、储能、阀门、继电器、激光、射频发射或安全联锁时，必须先确认安全状态、急停、能量隔离、超限保护和故障恢复。AI不得自行判断风险已被接受。
