# 新项目安装

1. 将本规范包复制到项目根目录，保留目录结构。
2. 确认AI工具能从根目录读取`AGENTS.md`；按需保留相应工具入口。
3. 在`project/ENABLED_DISCIPLINES.md`只启用当前项目需要的专业。
4. 在`PROJECT_PROFILE.md`和专业Profile中填写第一个任务所需的最小事实及来源；不要为了完整而猜值。
5. 依据`project-framework/项目目录框架_V1.20.md`创建启用专业的最小目录集合，未启用专业不必创建。
6. 检查规范文件没有覆盖项目源码、构建、硬件或测试资料。
7. 向AI发出首次只读任务：识别入口、目录、工具和未知项，不修改产品文件。
8. 核对结果后再开始开发，并创建首个任务级`work/<task-id>/`记录。

安装成功标准：入口可发现；规则链接可读取；专业选择生效；无项目文件被覆盖；AI能区分通用规则、项目事实和未知项。
