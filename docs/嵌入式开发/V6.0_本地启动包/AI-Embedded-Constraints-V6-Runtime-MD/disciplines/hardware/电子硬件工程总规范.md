# AI 嵌入式硬件开发具体约束

> 本文件只约束器件、原理图、电源、时钟、复位、数字/模拟接口、PCB、结构电气边界和制造输出。软件实现读取 `../software/嵌入式软件工程规范.md`；验证方法与结果判定读取 `../testing/真实测试与交付规范.md`。

## 1. 硬件输入与版本基线

- 开始前取得产品/板卡版本、原生可编辑原理图和PCB、库版本、BOM、结构边界、环境、接口表、数据手册修订和适用标准。
- PDF/图片可以审查，但不能冒充可编辑源；Gerber不能冒充原生PCB。
- 所有额定、阈值、间距和余量必须记录输入值、单位、来源版本/页码、公式或工具、最坏结果、设计裕量和验证方法。
- 输入冲突标记 `CONFLICT`；关键电压、负载、Pin、封装、材料、层叠或安全条件未知时禁止相应设计放行。

## 2. 器件、BOM 与库

- 核对完整 MPN、制造商、生命周期、温度/质量等级、额定、容差、降额、封装、Pin1/极性和引脚编号。
- 符号Pin、封装Pad、底部焊盘、隐藏电源脚、机械脚和数据手册必须一致。
- 禁止按功能名或封装名判断替代料等价；替代料分别验证参数、Pin、封装、固件识别、校准、认证和工艺。
- 绝对最大值不能作为连续工作点；最坏应力加项目规定裕量后仍须处于适用工作范围。
- EOL、NRND、单一来源、长交期和假货风险必须进入BOM风险和替代计划。

## 3. 电源树与热

- 每条电源轨计算 `I_rail,max = ΣI_load,max + I_dynamic + I_external`，未知负载不得按0计入。
- 线性稳压器至少计算 `P_loss=(V_in,max-V_out,min)×I_out,max+P_iq` 和 `T_j=T_a,max+P_loss×θ_effective`。
- 开关电源按适用效率曲线、导通/开关损耗、磁件损耗和最坏输入/负载计算。
- 储能下界为 `C_ideal >= I_step×Δt/ΔV_allow`，再按直流偏压、温度、容差、ESR/ESL修正有效值。
- 核对输入容差、稳态、峰值、启动、浪涌、短路、掉电、反灌、纹波、瞬态、补偿和磁件饱和。
- `θJA` 只有在板层、铜面积、气流和安装条件适用时才能使用，否则采用适用热模型或实测。
- 去耦必须对应具体电源脚并形成最小回路，禁止机械复制“每片0.1uF”或用大电容掩盖布局问题。

## 4. 时钟、复位与启动

- 晶体/振荡器核对频率、负载电容、ESR、驱动等级、容差、温漂、老化和启动裕量；外部电容计算必须注明寄生假设。
- 复位核对阈值、脉宽、上下拉、RC、多复位源逻辑、电源时序、按键和调试器影响。
- Boot Strap在采样窗口必须有确定电平，运行期复用不得冲突。
- 调试/下载接口必须定义访问边界、量产用途和恢复入口，测试点不得破坏高速或模拟性能。
- 任一合法供电、掉电、插拔和调试连接状态下不得出现不确定启动、闩锁或危险输出。

## 5. 数字接口与板级总线

- 每个方向计算 `NMH=VOH_min-VIH_min`、`NML=VIL_max-VOL_max`，在最坏电源、温度和负载下满足项目要求。
- 正常额定与绝对最大值分别核对；检查驱动/灌电流、三态、上拉域、带宽、未上电IO注入、反灌和方向争用。
- 电平转换器核对拓扑、方向控制、掉电高阻、开漏兼容和带宽；禁止仅凭“3.3V/5V兼容”判断。
- I²C上拉必须满足 `R_min=(VDD-VOL_max)/IOL_max` 和 `R_max=t_r_max/(0.8473×C_bus)` 的交集；`C_bus` 包含器件、PCB、连接器、线缆和探头。
- SPI/UART核对速率、拓扑、负载、时序和串阻；CAN/RS-485/USB/以太网核对阻抗、终端、共模、保护和连接器。
- ESD/EFT/浪涌保护必须比较钳位、残压、功率、结电容和失效模式与被保护器件能力。

## 6. 模拟、ADC 与传感器

- 建立传感器→保护→滤波/放大→ADC→算法的完整链路，记录量程、共模、源阻抗、增益、偏置、参考、带宽和采样时间。
- 误差预算包含初始误差、容差、温漂、噪声、参考、量化、非线性、布局寄生和校准残差，并说明最坏值或RSS方法。
- 全输入、全温度和故障条件下，每一级不得超出输入共模、输出摆幅、绝对最大值和注入电流。
- 运放/比较器核对稳定性、GBW、压摆率、输入偏置、输出负载和建立时间。
- 抗混叠截止频率、ADC采样率和数字滤波必须有一致的带宽依据；软件滤波不能弥补削顶、混叠或不稳定模拟链。
- 校准点、激励、标准器、温度条件、测试点和可追溯要求在设计阶段确定。

## 7. 原理图网络与ERC

- 解析所有页、层次端口、全局标签、电源符号、总线、网络别名、未连接标记和重复参考号。
- 生成器件-Pin-网络表；同名网络、跨页端口和层次方向必须一致，NC与遗漏逐项区分。
- ERC错误、警告和waiver分开；每个waiver记录规则、对象、工程理由、责任人、适用版本和期限。
- 修改前后比较器件数、网络数、关键网络成员、No Connect和电气类型，防止库更新或重编号引入隐性变化。
- 保存后关闭并重新打开原生工程，确认页、网络、库和对象未丢失。

## 8. PCB规则与布局布线

每条数值规则必须记录：

`对象/网络→输入及单位→来源版本/页码→公式或工具版本→最坏结果→裕量→EDA写入值→验证证据`

- 规则从板厂能力、层叠、铜厚、材料、电流、压降、温升、边沿、阻抗和安规条件推导；禁止使用“常用6/6mil”等经验默认值。
- 先固定板框、孔、连接器、天线、传感器、隔离区和结构关键件，再放电源、时钟、处理器、存储、模拟和普通器件。
- 去耦对应具体电源脚；开关电源高`di/dt`回路最小，SW节点远离反馈、时钟、模拟和天线。
- 高速/时钟/快速边沿信号必须有连续参考层；换层提供就近回流，禁止无依据跨平面分割。
- 电源路径检查线段、焊盘颈缩、过孔、连接器和开关器件全路径，不能只加宽主干。
- 大电流过孔计算成品孔径/孔铜下的电阻、损耗、温升、热耦合和电流分配，禁止简单用单孔能力乘数量放行。
- 差分对记录阻抗、线宽、间距、参考层、铜厚、介质厚度/介电常数、偏差、偏斜和层换结构，并与板厂确认值一致。
- 安规间距记录标准版本、工作/瞬态电压、材料组、污染等级、海拔、绝缘类别及涂覆/开槽条件。

## 9. 结构、热、EMC 与可靠性输入

- 板框、孔、槽、连接器、器件高度、禁布区、天线净空、散热器和线束必须绑定结构版本。
- 发热器件、温敏器件、气流、壳体接触和铜扩散协同，名义3D无干涉不能证明公差极限可装配。
- EMC/ESD设计必须明确端口、耦合路径、回流、滤波、屏蔽和保护布局；软件自动恢复不能替代必要硬件保护。
- 高压、隔离、爬电和电气间隙只能来自适用标准及项目条件，未知时禁止安全放行。
- RF按当前器件参考设计、频段、天线、匹配、净空、外壳和认证条件执行；未调试不得宣称射频性能通过。

## 10. DRC、制造输出与硬件交付

- 真实运行当前原生PCB和规则的DRC，保存工具版本、规则、原始报告、坐标和waiver。
- `0 DRC`只证明已配置规则未报错；仍须检查未布线、短路、断网、板框、孔、丝印、阻焊和制造能力。
- 制造包明确Gerber/ODB++层映射、钻孔/槽、板框、阻焊、钢网、原点、单位、镜像、PnP、BOM、装配图和版本。
- 输出后用独立查看器或回读解析核对层、孔、槽、外形、极性、原点和坐标，并生成逐文件大小/SHA-256清单。
- 只能报告实际等级：`PLAN_ONLY / EDITABLE_LAYOUT / ROUTED / DRC_VERIFIED / FAB_FILES_CHECKED / PHYSICALLY_TESTED`。
- 网表不一致、关键规则未知、关键DRC、未布线或回读失败时禁止制造放行；物理性能必须按 `../testing/真实测试与交付规范.md` 验证。
