# 新项目安装

1. 将根入口文件、`.github/copilot-instructions.md`和完整`.ai-engineering/`复制到项目根目录；不得把规范正文拆到其他位置。
2. 确认AI工具能从根目录读取`AGENTS.md`并继续读取`.ai-engineering/`；按需保留相应工具入口。
3. `project/ENABLED_DISCIPLINES.md`初始必须保持`UNINITIALIZED`，按项目或首个任务显式选择专业，不默认软件。
4. 在`project/PROJECT_PROFILE.md`、命中的专业Profile和`TOOL_CAPABILITIES.md`中填写首个任务所需的最小事实及来源；不要为了完整而猜值。
5. 依据`project-framework/项目目录框架_V1.20.md`创建启用专业的最小业务目录集合，未启用专业不必创建。
6. 检查规范文件没有覆盖项目源码、构建、硬件或测试资料。
7. 向AI发出首次只读任务：识别入口、目录、工具和未知项，不修改产品文件。
8. 核对AI加载回执后再开始开发，并创建首个任务级`work/<task-id>/`记录。

安装成功标准：入口可发现；`.ai-engineering/`位置固定且完整；规则链接可读取；专业选择生效；无项目文件被覆盖；AI加载回执能列出通用规则、强制Profile、局部约束和未知项。
