# 版本升级与冲突处理

1. 读取旧版`VERSION.md`、`MANIFEST.md`、`PACKAGE_MANIFEST.md`和适用的`UPGRADE_MIGRATION.md`，列出用户修改、项目事实和任务记录。
2. 备份所有将被替换的规范管理文件；`.ai-engineering/project/`和`work/`永不直接覆盖。
3. 比较规则正文，区分新增、澄清、不兼容和本地定制。
4. 工具入口采用三方合并，只更新路由；不得把新规则复制进入入口。
5. 新增Profile字段保留为`UNKNOWN`，不得覆盖已有确认值和来源。
6. 规则冲突按`rules/00_规范效力与加载规则.md`处理并记录决定。
7. 验证所有内部链接、入口路由、专业独立启用和现有项目目录映射。
8. 通过后重新核对包级清单与关键SHA-256，更新版本和文件清单，创建单一升级检查点。

升级失败时恢复备份或回退检查点；不得留下部分新规则、部分旧入口的混合状态。
