# 机械、热与可靠性规范

本专业可独立用于结构、装配、热和环境可靠性分析。电子硬件只提供功耗、边界和接口，不替代本专业判定。

- 输入必须包含结构版本、材料、尺寸与公差、安装方向、连接器/线束、质量、冲击振动、温湿度、防护、散热条件和任务剖面。
- 公差分析覆盖极限组合、装配顺序、紧固、形变、磨损、热膨胀和维护空间；名义3D无干涉不能证明可装配。
- 热分析使用真实功耗、接触热阻、界面材料、气流、辐射和环境边界；模型记录网格、材料、边界、求解器及相关性验证。
- 温度结论必须覆盖稳态、瞬态、启动、峰值负载和故障；结温、表面温度、材料和电池限值分别判定。
- 可靠性计划从任务剖面和失效机理推导，不套用固定温度、振动或寿命时长；样本量、应力、失效判据和统计方法必须明确。
- 机械、热或环境变更必须传播到PCB禁布、高度、连接器、天线、传感器、校准和测试。
- 仿真通过不能替代样机测温、装配、冲击振动或环境试验；无实物证据时保持`NOT_RUN/UNAVAILABLE`。
