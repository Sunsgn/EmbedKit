# 现有项目目录映射规则

接入已有项目时建立下表，不复制或移动项目文件即可完成映射：

| V1.20职责 | 现有路径 | 状态 | 权威内容 | 缺口/动作 |
|---|---|---|---|---|
| 项目管理与需求 | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN |
| 软件源码与构建 | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN |
| 硬件原理图与PCB | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN |
| 测试与原始证据 | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN |
| 发布与生产资料 | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN |
| AI任务记录 | `work/`或项目指定路径 | 待确认 | 任务级目录 | 不覆盖历史任务 |

映射状态使用`COVERED`、`PARTIAL`、`MISSING`、`NOT_APPLICABLE`。路径必须相对项目根目录且可定位；同一职责存在多个来源时明确唯一权威文件。只有用户批准目录整理后才执行移动或重命名。
