# PCB设计工作流

1. 锁定原理图网表、板框、结构、层叠、制造能力、接口和板卡版本。
2. 从电气、器件、安规和制造要求推导网络类与规则，禁止无来源经验默认值。
3. 完成分区、固定器件、关键功能布局和可测性评审。
4. 按电源、高速/差分、时钟、模拟、开关、普通信号顺序完成关键布线审核。
5. 核查回流、大电流、热、串扰、EMC、安全间距和DFM/DFT。
6. 执行DRC并逐项处理或记录豁免；AI不能操作EDA时状态保持`PLAN_ONLY`。
7. 生成制造输出，并用独立查看器回读Gerber、钻孔、板框、层、阻焊、钢网和坐标。
8. 记录源文件与输出哈希、版本、问题及状态；满足规范门禁后才能`DRC_VERIFIED`。
