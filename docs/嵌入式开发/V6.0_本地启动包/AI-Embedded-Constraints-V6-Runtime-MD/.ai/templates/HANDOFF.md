## 恢复前必须复核

1. 重新读取根 `AGENTS.md`、Profile 和当前任务命中的约束。
2. 检查 Git 状态，不覆盖用户新修改。
3. 重新计算关键输入和产物哈希。
4. 判断上次非幂等动作是否已发生；状态不明时不得重放。
5. 从最近有有效证据的检查点继续，而不是从聊天记忆继续。
