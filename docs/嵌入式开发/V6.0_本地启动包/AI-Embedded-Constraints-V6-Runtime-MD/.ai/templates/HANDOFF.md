# 跨会话交接

## 强制记录合同

- 触发条件：会话即将结束、任务中断、切换执行者或存在未完成长任务。
- 必须执行：记录基线、输入身份、修改、命令、结果、风险、下一安全动作和禁止重放事项。
- 禁止：仅写“继续上次任务”、依赖聊天记忆或把状态未知的非幂等动作标成可重试。
- 有效条件：新执行者无需猜测即可复核基线并从最近有效检查点继续。
- 失败处理：交接缺关键身份或恢复动作时不得自动续跑，先重新调查并将状态保持 UNKNOWN/BLOCKED。

## 恢复前必须复核

1. 重新读取根 `AGENTS.md`、Profile 和当前任务命中的约束。
2. 检查 Git 状态，不覆盖用户新修改。
3. 重新计算关键输入和产物哈希。
4. 判断上次非幂等动作是否已发生；状态不明时不得重放。
5. 从最近有有效证据的检查点继续，而不是从聊天记忆继续。
