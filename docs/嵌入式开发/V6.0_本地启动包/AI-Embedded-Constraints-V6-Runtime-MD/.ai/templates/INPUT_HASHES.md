# 关键输入与产物身份

## 强制记录合同

- 触发条件：任务依赖需求、协议、设计、配置、源码基线或生成产物，或需要跨会话恢复。
- 必须执行：记录稳定身份、时间和变化处理；不能计算 SHA-256 的对象必须记录等价版本/设备身份及原因。
- 禁止：以文件名、路径或修改时间作为唯一身份；输入变化后不得沿用依赖旧输入的 PASS。
- 有效条件：所有会改变结论的关键输入和输出都能唯一关联当前任务。
- 失败处理：身份缺失或变化时使依赖结论失效，重新执行影响分析和对应验证。

| 对象 | 类型 | 版本/大小 | SHA-256 或其他稳定身份 | 记录时间 | 变化后的处理 |
|---|---|---:|---|---|---|

至少记录当前任务依赖的需求、项目约束、协议、原理图/PCB、构建配置、源码基线、测试配置和新产物。输入变化后，依赖该输入的旧结论自动失效，必须重新影响分析和验证。
