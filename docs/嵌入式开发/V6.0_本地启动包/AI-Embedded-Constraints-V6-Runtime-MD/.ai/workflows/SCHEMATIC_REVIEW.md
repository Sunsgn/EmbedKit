# 原理图开发与审查工作流

## 强制执行合同

- 触发条件：新增、修改或审查原理图、器件、BOM、电源、接口或关键器件替代。
- 必须执行：锁定原生工程和资料，建立器件-Pin-网络证据，完成项目适用检查并运行可用的真实 ERC。
- 禁止：用 PDF 视觉检查代替原生网络、库、ERC、仿真或样机测量；不得自行批准 waiver。
- 有效条件：所有结论与原生工程/库/BOM 版本绑定，错误、警告、豁免和未执行验证分别记录。
- 失败处理：关键参数、网络、封装、额定或安全输入未知/冲突时停止采购、制板和相关放行。

1. 锁定原生工程、库、BOM、板卡版本、数据手册、供电/负载、环境、法规和结构输入。
2. 解析所有页、层次连接、网络、电源、未连接引脚和重复引用，生成可回跳器件-Pin-网络表。
3. 核对完整料号、额定、容差/降额、封装、Pin、极性、生命周期和替代料。
4. 审查电源树、启动/掉电、反灌、保护和热；审查时钟、复位、Boot 和调试入口。
5. 核对数字电平/方向/终端，建立模拟链路和误差预算；安全/RF/高压缺关键参数时阻塞。
6. 在实际可用 EDA 中运行 ERC，逐项处理错误、警告和批准 waiver；保存原始报告和差异。
7. 输出对软件、PCB、测试、生产、结构和现场兼容的影响。

PDF 静态审查不能冒充原生 EDA、仿真或样机测量；缺工具时相应状态为 `UNAVAILABLE/NOT_RUN`。
