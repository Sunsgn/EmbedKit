# 新板 Bring-up 工作流

## 强制执行合同

- 触发条件：任务涉及新板首次上电、板级故障隔离或逐级启用硬件。
- 必须执行：下列步骤按顺序执行；跳过项必须标记 `N/A` 并提供当前板卡证据和理由。
- 禁止：关键电源、短路、极性、安全输出或限流状态未知时上电；不得用软件读回替代必要物理测量。
- 有效条件：每个已执行步骤均绑定板卡、固件、仪器和原始测量；未上板只能报告 `PLAN_ONLY/NOT_RUN`。
- 失败处理：任一步异常立即停止后续使能，保存首次失败并回到最近安全检查点；未经解释不得反复上电。

1. 锁定板号、原理图/PCB/BOM/返修状态、供电和限流来源；隔离危险输出。
2. 断电检查短路、极性、关键阻值和错件；异常未解释前不得反复上电。
3. 使用限流电源逐路测量电压、电流、纹波、启动/掉电和异常温升。
4. 测量时钟、复位、Boot Strap 和调试接口电平/时序；不以软件读回替代物理测量。
5. 使用匹配目标的最小固件，从安全 GPIO/调试标记开始，逐级启用内存、定时器、中断、外设、DMA、总线和应用。
6. 每步保存已知好检查点，失败回退并一次只改变一个变量。
7. 崩溃保留复位原因、故障寄存器、PC/LR/栈，并使用同哈希 ELF/MAP 解析。
8. 保存板卡、固件、仪器设置、波形、总线捕获和异常记录。

真实上电、下载和执行器动作需要相应授权；无板卡/仪器时只能输出 `PLAN_ONLY/NOT_RUN`。
