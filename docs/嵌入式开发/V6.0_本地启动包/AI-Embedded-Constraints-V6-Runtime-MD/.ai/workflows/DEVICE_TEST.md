# 真实设备与集成测试工作流

1. 锁定需求/用例、源码和固件哈希、硬件/BOM、配置、设备 ID、工具/工装和环境。
2. 执行设备、端口、供电、仪器校准和工装自检；环境失败与产品失败分开。
3. 每个用例在执行前定义前置、步骤、输入、阈值来源、期望、清理和证据。
4. 连接和操作前确认目标对象；烧录、危险输出、故障注入和生产设备需要额外授权。
5. 执行正常、边界、非法、断开、复位、资源不足、恢复和兼容中的适用场景。
6. 同步采集设备日志、原始帧/抓包、波形/测量和测试步骤，关联同一时间或事务。
7. 保留首次失败，自动重试只用于已分类的基础设施瞬态问题且不得隐藏产品失败。
8. 停止/取消/失败时安全关闭设备、端口和仪器，恢复目标状态。

报告按 `PASS/FAIL/BLOCKED/NOT_RUN/UNAVAILABLE` 汇总，不能把未执行、环境失败或模拟结果计为真实设备 PASS。
