# PCB 修改与制造输出工作流

## 强制执行合同

- 触发条件：修改原生 PCB、布局布线、设计规则或生成制造输出。
- 必须执行：锁定输入基线、从项目参数推导规则、验证可编辑文件、真实运行 DRC，并独立回读制造输出。
- 禁止：套用样例线宽/间距/阻抗/安规值；无真实 EDA 时不得声称完成布线或 DRC。
- 有效条件：设计等级、DRC、未布线数、原始报告、制造清单和哈希均与同一输入版本绑定。
- 失败处理：网表、封装、板框、规则来源冲突或关键 DRC 未关闭时停止制造放行并保留 RC/FAIL。

1. 锁定匹配的原理图/网表、BOM/封装、板框/结构、层叠、板厂能力、阻抗、电流和安全要求。
2. 核对器件/Pin/Pad、板框、孔、keepout 和版本；网表不一致先回到权威源解决。
3. 从真实电流、压降、阻抗、热、安全和制造能力推导并录入规则，禁止套用样例数值。
4. 按结构关键件、电源、时钟、处理器/存储、模拟和普通器件顺序布局，核对回流和热路径。
5. 按关键网络优先布线，处理参考层、换层回流、差分、过孔、平面孤岛和颈缩。
6. 自动写回只在可恢复副本，记录对象操作并重新打开原生文件验证。
7. 真实运行 DRC，保留未布线数、原始报告、整改和复跑结果。
8. 生成 Gerber/钻孔/BOM/PnP/装配等制造包，用独立查看器回读并生成哈希清单。

只报告实际达到的 `PLAN_ONLY/EDITABLE_LAYOUT/ROUTED/DRC_VERIFIED/FAB_FILES_CHECKED/PHYSICALLY_TESTED` 等级；无 EDA 不得生成假布线或假 DRC。
