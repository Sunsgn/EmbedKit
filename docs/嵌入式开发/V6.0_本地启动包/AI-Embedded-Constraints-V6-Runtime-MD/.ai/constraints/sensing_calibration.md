# 传感、测量、计量与校准详细约束

## CAL-001：适用范围与测量链

适用于温度、压力、气体、流量、光、电量、惯性、位置等传感，以及 ADC、数字传感器、工程量换算和计量校准。开始前建立“被测量→传感器→模拟/数字接口→原始码→补偿→工程量→判定/控制”的完整链，记录单位、量程、精度、环境和追溯要求。

- 明确测量对象、安装位置、动态范围、响应时间和实际使用环境。
- 区分分辨率、重复性、准确度、线性、迟滞、漂移和检测限，禁止用 ADC 位数宣称系统精度。
- 每段转换的方向、符号、缩放、偏置、饱和和无效值语义一致。

## CAL-002：传感器与模拟前端

- 核对供电、预热、源阻抗、共模、增益、偏置、带宽、噪声、参考、保护和输入绝对额定值。
- ADC 采样时间和前端建立满足源阻抗；多路切换考虑残留、串扰和首样丢弃/等待策略。
- 数字传感器核对总线、地址、量程配置、转换时间、状态/CRC 和数据就绪，禁止用固定 sleep 代替可用状态而无上界。
- 机械应力、气流、热源、冷凝、污染和安装方向对测量的影响必须进入设计和试验。

## CAL-003：单位、数值与算法

- 原始码、校准系数、中间量和输出量都声明单位/缩放；协议和 UI 不得各自维护不一致换算。
- 计算检查符号扩展、中间溢出、除零、舍入、截断、NaN 和饱和，边界前后行为确定。
- 滤波、平均、去毛刺和异常剔除记录窗口、延迟和对真实快速变化的影响；禁止为了平滑曲线隐藏危险变化。
- 温度/非线性补偿模型记录来源、有效范围、系数版本和外推行为，范围外不得无提示延伸。

## CAL-004：误差预算与不确定度

- 误差预算包含传感器、前端、参考、ADC、量化、噪声、温漂、供电、机械、算法、校准标准和残差。
- 说明使用最坏值、RSS 或计量不确定度方法的依据，相关误差不得错误当独立项合成。
- 精度结论限定到量程、温度、供电、老化和安装条件；典型值不能替代保证值。
- 当预算超过需求时，应调整设计、校准或需求，不得通过减少测试点隐藏。

## CAL-005：校准设计与数据模型

- 定义零点、跨度、多点、温度和交叉量校准策略，点位覆盖工作范围和关键阈值两侧。
- 校准标准具有量程、准确度/不确定度、溯源和有效期，标准能力应优于被校对象并满足项目规则。
- 原始测量、标准值、环境、拟合方法、系数、残差、算法和工装版本全部保存；只保存最终系数不可复核。
- 校准数据含设备/通道身份、schema、版本、长度、CRC/认证和原子写入，不能写错设备或被默认值覆盖。

## CAL-006：生产、现场和再校准

- 生产校准具有工装自检、防错、稳定条件、操作顺序、失败隔离和重复校准策略。
- 校准系数与序列号、硬件/BOM、固件和时间关联；更换传感器、模拟前端或关键固件后评估失效。
- 现场校准区分用户零点、服务校准和法定计量权限，不能让普通命令修改受控参数。
- 规定校准周期、漂移监测、到期行为和恢复出厂策略；恢复不得删除依法需要的历史记录。
- 多通道或多传感器设备必须防止通道、序列号和系数错配；复制配置、换板、换传感器和返修后执行身份一致性检查。
- 校准算法或系数格式升级建立旧数据迁移、双向兼容和失败回退，不能因软件升级静默重置有效校准。

## CAL-007：验证、异常与诊断

- 使用独立验证点而非全部复用拟合点，覆盖零/中/满量程、关键阈值、温度和重复性。
- 测试开路、短路、冻结、突变、超量程、CRC 错误、预热不足和校准损坏，区分真实极端值与传感故障。
- 诊断记录原始码、工程量、状态、校准版本和限频错误，但保护隐私/安全数据。
- 模拟输入只能验证算法；真实精度必须由完整传感链和可溯源标准验证。

## CAL-008：证据、验收与失败门禁

证据包括测量链、数据手册、单位表、误差预算、校准计划、标准溯源、原始/拟合/残差数据、系数身份、独立验证和异常测试。单位不一致、预算无依据、标准过期、设备身份不匹配、校准数据掉电损坏或阈值附近误差超限时禁止计量/控制功能放行。
