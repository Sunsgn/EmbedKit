# 硬件电源、时钟、复位与数字接口原子约束

## HPD-001：输入、工作模式与最坏条件

- 触发条件：设计/修改供电、数字器件、接口、时钟、复位或关键器件。
- 必须执行：列出输入容差、负载模式、启动/峰值/睡眠/故障电流、温湿度、寿命和目标标准；计算使用最坏组合并注明余量。
- 禁止：只用典型值、开发板测值或标称电压；把绝对最大额定当可连续工作条件。
- 必需证据：需求、数据手册版本、工作模式表、计算书和样机测量计划/结果。
- PASS 条件：每个额定/阈值/余量有来源，最坏工作点不越推荐范围且故障进入规定状态。
- 失败处理：关键环境或负载未知时阻止额定和放行结论。

## HPD-002：电源树、稳压与启动裕量

- 触发条件：新增/修改输入保护、LDO、DC/DC、电源开关、负载开关或电源域。
- 必须执行：逐轨由负载清单计算 `I_rail,max=ΣI_load,max+I_dynamic+I_external`；线性稳压器计算 `P_loss=(V_in,max-V_out,min)×I_out,max+P_iq`、`T_j=T_a,max+P_loss×θ_effective`，开关电源使用适用效率曲线及开关/导通/磁件损耗；同时核对压降、纹波、瞬态、启动、浪涌、反灌、稳定区和器件应力。
- 禁止：只按平均电流选型；忽略线缆/连接器压降；未验证环路/输出电容条件；用软件限制替代必要硬件保护。
- 必需证据：逐负载电流表、带单位和来源页码的损耗/结温/裕量计算、电源树、BOM/原理图位置、仿真（适用时）及电压/电流/纹波/温升波形。
- PASS 条件：稳态与瞬态均在范围内，启动/短路/掉电无危险或反灌，热和余量符合项目准则。
- 失败处理：峰值或保护行为未测时不得完成电源放行。

## HPD-003：去耦、旁路与储能

- 触发条件：放置/修改 IC 电源、电容、参考、电源入口或高 di/dt 负载。
- 必须执行：按数据手册为每个电源脚配置局部高频去耦；以 `C_ideal>=I_step×Δt/ΔV_allow` 建立储能下界，再按直流偏压、温度、容差、ESR/ESL修正有效电容，并核对浪涌、环路稳定性和允许电容范围。
- 禁止：按“每片一个 0.1uF”机械复制；忽略 MLCC 直流偏压；多个电源脚共享长支路；用大电容替代正确回路布局。
- 必需证据：器件建议、有效容值计算、电源脚-电容-地回路、BOM 和瞬态/纹波测量。
- PASS 条件：每个关键电源脚具有最小回路，容量覆盖频段/瞬态，器件额定和浪涌安全。
- 失败处理：布局无法满足时回到 PCB/器件位置整改，不能只增加标称容值。

## HPD-004：上电、掉电、反灌与电源域交互

- 触发条件：多电源域、可插拔、USB/调试器供电、电池/适配器切换或未上电 IO。
- 必须执行：核对各轨顺序、斜率、复位保持、掉电、IO 注入和所有外部连接状态；设计隔离、限流、理想二极管或高阻状态。
- 禁止：假定电源总同时出现；忽略信号脚/调试口反向供电；未上电器件被外部高电平驱动而不核对注入电流。
- 必需证据：时序图、器件绝对额定/掉电行为、插拔/断电波形和异常电流测量。
- PASS 条件：任意允许供电组合无闩锁、反灌或不确定输出，复位和安全状态保持。
- 失败处理：组合未验证时限制使用场景并保持相关测试 NOT_RUN。

## HPD-005：时钟、晶体与振荡器

- 触发条件：新增/修改晶体、振荡器、时钟缓冲、PLL 输入或时钟布线接口。
- 必须执行：核对频率、负载电容、ESR、驱动等级、容差/温漂/老化、启动裕量和器件推荐；计算外部电容并注明寄生假设。
- 禁止：直接复制参考板电容；用普通探头测量导致停振却仍下结论；将能起振等同于全温全压满足。
- 必需证据：数据手册、计算、布局要求、启动时间/幅度/频率测量及适用温压验证。
- PASS 条件：驱动和负阻裕量符合器件依据，启动/精度满足系统要求，布局可实现最小回路。
- 失败处理：无合适测量条件时保留样机验证 NOT_RUN。

## HPD-006：复位、Boot Strap 与调试接口

- 触发条件：修改复位、启动模式、按键、监控芯片、调试/下载或量产接口。
- 必须执行：核对阈值、脉宽、上下拉、RC、多个复位源逻辑、电源时序和调试器影响；Boot 脚在采样窗有确定电平，之后复用不冲突。
- 禁止：仅靠 MCU 内部上拉保证关键启动；复位 RC 超出器件输入要求；量产调试口无访问边界；测试点改变高速/模拟行为。
- 必需证据：复位/Boot 真值及时序、计算、原理图、上电/掉电/按键/调试器连接波形。
- PASS 条件：所有供电和连接状态可靠进入规定模式，复位释放后时钟/电源稳定，恢复入口可控。
- 失败处理：默认启动状态不确定时禁止制板/量产放行。

## HPD-007：数字电平、方向与电平转换

- 触发条件：连接不同器件/电压域的 GPIO、UART、SPI、并行或控制信号。
- 必须执行：逐端在最坏电源/温度/负载下计算 `NMH=VOH_min-VIH_min`、`NML=VIL_max-VOL_max`，另行核对驱动/灌电流、绝对最大值、方向、三态、上拉域、速度和掉电状态；电平转换核对拓扑、方向控制、压降和带宽。
- 禁止：仅凭“3.3V/5V 兼容”判断；双向推挽直接相连；掉电侧钳位反灌；自动方向转换用于不满足其边沿/负载条件的接口。
- 必需证据：接口矩阵、最坏电平计算、器件曲线、原理图/布局约束和适用波形。
- PASS 条件：`NMH/NML` 均达到项目来源要求，正常额定、绝对最大值、带宽和上电状态均满足，任何合法方向无总线争用。
- 失败处理：对端型号/供电未知时接口保持未确认，不得选电平转换方案。

## HPD-008：I²C、SPI、UART、CAN/差分物理层

- 触发条件：设计或修改板级通信接口。
- 必须执行：I²C 计算 `R_min=(VDD-VOL_max)/IOL_max`、`R_max=t_r_max/(0.8473×C_bus)` 并证明存在交集，电容包含器件、PCB、连接器/线缆和探头；SPI/UART 核对速率、时序、拓扑、源端/负载和串阻；CAN/RS-485/USB/以太网核对阻抗、终端、共模、保护和连接器。
- 禁止：无计算套用上拉/终端；分支和线长不计入；保护器件电容/残压破坏信号；终端位置错误。
- 必需证据：拓扑、线缆/板级参数、计算、器件选型、原理图和眼图/边沿/误码或总线测量（适用时）。
- PASS 条件：最坏负载和环境下电气/时序满足标准及器件范围，异常连接不会损坏设备。
- 失败处理：缺线缆/对端信息时明确适用边界，不能报告系统接口 PASS。

## HPD-009：器件额定、降额与替代料

- 触发条件：选型、BOM 变更、替代料、PCN/EOL 或成本优化。
- 必须执行：核对完整 MPN、封装、Pin、温度/质量等级、电压/电流/功率/频率/精度和寿命；按项目降额准则比较最坏应力。
- 禁止：按功能名或封装名判等价；使用绝对最大值作设计点；忽略固件识别、校准、工艺和认证差异。
- 必需证据：数据手册版本、应力/降额表、符号-Pin-封装映射、样机与回归计划/结果。
- PASS 条件：所有关键参数满足且无未评估跨专业影响，替代料具有批准范围。
- 失败处理：任何关键参数/生命周期未知时不得批准替代。

## HPD-010：硬件数字与电源完成门禁

- 触发条件：电源、时钟、复位、数字接口或器件变更准备放行。
- 必须执行：完成原生工程检查、计算、ERC、接口矩阵、跨软件/PCB/测试影响和适用样机测量。
- 禁止：用 PDF、ERC 零错误或单一典型样机替代全部证据。
- 必需证据：原生文件/库/BOM 哈希、计算、ERC、波形、版本差异和 waiver。
- PASS 条件：无额定/Pin/网络冲突，所有关键未知关闭或明确阻塞，验证层级如实。
- 失败处理：关键输入缺失时停止采购、制板或发布，不得用经验数值填充。
