# PCB 叠层、布局与信号布线原子约束

## PLS-001：输入基线与规则来源

- 触发条件：开始布局、布线、规则修改或设计复核。
- 必须执行：锁定原理图/网表、封装库、板框/结构、层叠、铜厚、材料、板厂能力、阻抗、电流、接口速率和安规输入；建立版本关联。
- 禁止：从模板板复制规则而不验证；网表/封装/板框冲突时继续；以 EDA 默认规则作为项目依据。
- 必需证据：输入清单与哈希、规则来源表、板厂/结构/标准版本和冲突记录。
- PASS 条件：每条规则可追溯到当前工程事实，所有关键输入一致。
- 失败处理：缺层叠、材料或结构时仅允许概念布局，不得完成阻抗/安规/制造结论。

## PLS-002：叠层、参考层与回流路径

- 触发条件：确定层数、层序、信号层、平面或高速/敏感网络换层。
- 必须执行：依据发送器上升/下降时间、互连传播延迟和拓扑判断传输线风险；为每个高速/时钟/快速边沿信号指定连续参考层；换层提供邻近回流过孔/电容；评估平面开槽、分割和板边路径。
- 禁止：高速信号跨地/电源分割；参考层中断而无回流桥；只按频率忽略上升时间；薄长平面颈缩承载回流。
- 必需证据：叠层表、关键网络-参考层映射、换层/跨区检查和场求解/阻抗依据（适用时）。
- PASS 条件：所有关键信号回流连续且环路最小，层叠可由目标板厂制造并满足阻抗/厚度要求。
- 失败处理：参考层不可保证时调整层叠/布局，不能靠后期串阻默认修复。

## PLS-003：器件布局和功能分区

- 触发条件：放置连接器、电源、处理器/存储、时钟、模拟、RF、功率或关键器件。
- 必须执行：先固定结构/安全/接口器件，再按信号流、电源流、回路、热和装配安排；关键器件按数据手册限定相对位置和朝向。
- 禁止：只追求飞线最短；将敏感模拟/晶体置于开关节点或大电流回路旁；忽略维修、测试、贴装和外壳高度。
- 必需证据：布局约束、关键回路标注、3D/结构检查、器件间距和跨专业评审记录。
- PASS 条件：功能块边界与回流一致，关键回路可按规则布线，热/结构/装配无未解决冲突。
- 失败处理：关键器件无法满足布局要求时先调整板框/架构，不得进入普通布线掩盖问题。

## PLS-004：线宽、间距、过孔与网络类

- 触发条件：建立或修改设计规则、网络类、过孔和差异化约束。
- 必须执行：每条数值规则记录“对象/网络→输入及单位→来源版本/页码→公式或工具版本→最坏结果→裕量→EDA 写入值”；从板厂能力、电流/温升/压降、铜厚和内外层、阻抗、电压、安规及可制造余量推导线宽/间距/过孔，并检查焊盘颈缩、过孔和连接器全路径。
- 禁止：所有网络使用同一默认值；以 IPC/在线计算器单一结果代替项目条件；使用低于板厂稳定能力的极限值而无批准。
- 必需证据：完整规则推导表、EDA 规则导出、网络类成员、板厂能力/阻抗确认及电源路径最窄点清单。
- PASS 条件：每个关键网络属于正确规则类，EDA 设置与计算一致，制造公差仍满足要求。
- 失败处理：数值来源不全时保持 UNKNOWN，不得用“常用 6/6 mil”等补齐。

## PLS-005：时钟、晶体和快速边沿

- 触发条件：布线晶体、振荡器、时钟、复位或快速控制边沿。
- 必须执行：晶体回路最短、对称、少过孔、避噪声并按器件建议接地/屏蔽；时钟指定参考层、受控阻抗/源端阻尼依据和远离敏感网络。
- 禁止：晶体走线下方穿越其他信号/开关回流；测试点形成长支桩；时钟跨分割或靠近板边/连接器无评估。
- 必需证据：数据手册布局要求、走线长度/层/回流检查、启动/抖动/过冲测量计划或结果。
- PASS 条件：关键回路和回流符合器件/系统要求，无无意支桩，目标板验证满足启动和信号质量。
- 失败处理：没有测量时只能报告布局规则满足，不能宣称时钟性能通过。

## PLS-006：差分对与高速串行接口

- 触发条件：USB、Ethernet、LVDS、MIPI、PCIe 或其他差分/高速链路。
- 必须执行：记录线宽、间距、参考层、铜厚、介质厚度/介电常数和制造公差，通过当前层叠场求解或板厂阻抗表设置单端/差分阻抗、长度/对内偏斜、过孔和连接器；减少层换与支桩并保持对称。
- 禁止：只匹配总长度忽略局部不连续；为蛇形等长引入过度近场耦合；差分对跨分割、分开绕障碍或经过不对称焊盘而不评估。
- 必需证据：规则来源、场求解/板厂阻抗、长度/偏斜报告、过孔/连接器模型和眼图/合规测试（适用时）。
- PASS 条件：EDA 几何与当前板厂确认值及协议预算一致，回流连续，制造后阻抗/链路验证达到项目层级；只修改阻抗标签而未更新几何不得 PASS。
- 失败处理：缺链路速率/层叠时不得确定几何和宣称高速完成。

## PLS-007：单端总线、拓扑、端接与支桩

- 触发条件：SPI、并行存储、地址/数据总线、长 GPIO、外部时钟或多负载高速信号。
- 必须执行：根据边沿、拓扑、驱动、负载和长度确定点到点/菊链/星形及源端/并联端接；控制支桩和分支位置。
- 禁止：按逻辑频率判断无需 SI；多负载任意星形；串阻远离驱动端；测试焊盘形成未计入支桩。
- 必需证据：拓扑图、临界长度/端接计算、布局/走线、仿真或过冲/振铃/建立保持测量。
- PASS 条件：最坏负载下电平和时序满足接收器要求，端接不造成额外功耗/电平问题。
- 失败处理：模型不足时预留可调端接并安排实测，不得固定未经验证值。

## PLS-008：模拟、数字和敏感网络布线

- 触发条件：ADC/DAC、参考、传感器、音频、小信号、基准或高阻节点布线。
- 必须执行：保持信号与回流相邻，缩小高阻/敏感节点，远离时钟/开关节点/大电流；差分模拟保持对称，保护和滤波器按信号进入顺序放置。
- 禁止：机械切割地平面代替回流设计；数字线穿过模拟参考区；保护器件到连接器回路过长；高阻节点大面积暴露。
- 必需证据：敏感网清单、回流/耦合检查、布局规则和噪声/串扰/精度测量。
- PASS 条件：敏感链路无高 di/dt 共阻抗路径，保护回路优先泄放，噪声满足误差预算。
- 失败处理：不能隔离时重新布局或调整架构，不得仅靠软件滤波声明完成。

## PLS-009：过孔、焊盘、泪滴与制造几何

- 触发条件：换层、扇出、BGA、连接器、大电流或高可靠性设计。
- 必须执行：按板厂成品孔径、纵横比、环宽和孔铜设置过孔；评估 via-in-pad、盲埋孔、背钻和填孔工艺；高电流过孔阵列计算单孔电阻/损耗/温升并考虑热耦合和电流分配，不得将单孔能力简单乘数量作为放行值。
- 禁止：使用板厂不可控极限；单过孔承载未验证大电流；高速层换无回流过孔；机械孔/槽与铜/走线无公差余量。
- 必需证据：板厂能力、过孔表、BGA 扇出检查、热/电流计算和可制造性评审。
- PASS 条件：几何在稳定工艺窗口内，电气/热/可靠性满足要求，特殊工艺已明确报价与检验。
- 失败处理：工艺未经目标厂确认时不得输出正式制造包。

## PLS-010：布局布线完成门禁

- 触发条件：宣称完成布局、布线、信号完整性或准备进入制造检查。
- 必须执行：运行真实 DRC，检查未布线、网络类、关键长度/偏斜、参考层、跨分割、支桩、结构和适用 SI 测量/仿真。
- 禁止：仅以 DRC 零错误证明 SI/功能；无 EDA 时生成假布线/假 DRC；隐藏批准豁免。
- 必需证据：原生 PCB、规则、DRC 原始报告、对象统计、关键网审查和 waiver。
- PASS 条件：无未处置错误/未布线，所有关键网络满足其规则且验证层级准确。
- 失败处理：保留 `EDITABLE_LAYOUT/ROUTED/DRC_VERIFIED` 等实际等级，不得越级报告。
