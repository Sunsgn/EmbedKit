# PCB 电源、热、EMC 与可制造性原子约束

## PPEM-001：电源路径、电流与压降

- 触发条件：布线电源、地、大电流、连接器、保险、功率器件或电池路径。
- 必须执行：按最坏 RMS/峰值/脉冲、铜厚、长度、允许压降/温升和环境推导铜宽/面积/过孔；识别瓶颈、颈缩和回流共享。
- 禁止：只看平面面积不检查最窄处；用单个过孔或焊盘颈缩承载大电流；把外层/内层铜温升等同；忽略连接器和保险压降。
- 必需证据：电流路径图、计算/仿真、规则、铜厚/板厂条件和压降/温升测量。
- PASS 条件：所有路径最坏压降/温升在预算内，无隐藏瓶颈，保护器件和连接器额定匹配。
- 失败处理：负载或铜厚未知时禁止确定电源几何和功率放行。

## PPEM-002：去耦布局和高频电流回路

- 触发条件：放置/布线去耦、旁路、参考和高速数字电源。
- 必须执行：电容按频段和电源脚就近放置；连接顺序和过孔使 IC-电容-地环路最小；电源/地过孔避免共用长支路。
- 禁止：电容靠近但回流绕行；电源先穿过长细线再到电容；多个高速电源脚共享单细过孔；仅靠整面电源层认定已去耦。
- 必需证据：逐电源脚去耦检查、回路面积、过孔/平面连接和目标纹波/瞬态测量。
- PASS 条件：每个关键电源脚有低电感局部回路，储能路径和频段覆盖符合电路设计。
- 失败处理：器件摆放阻止最小回路时必须回到布局调整。

## PPEM-003：开关电源 PCB 回路

- 触发条件：布置 Buck/Boost/Flyback/充电器、门极驱动或其他开关功率级。
- 必须执行：标出输入热回路、开关回路、整流/输出回路、门极回路和反馈/补偿；最小化高 di/dt 环路与 SW 铜，反馈从安静点 Kelvin 取样。
- 禁止：SW 铜无必要扩大；反馈线靠近/跨越 SW 或电感；功率地和信号地随机共路；自举/栅极器件远离管脚。
- 必需证据：芯片布局指南、回路标注、铜/过孔检查、开关节点/栅极/纹波/EMI 波形。
- PASS 条件：关键回路紧凑、反馈安静、热路径连续，稳定性、纹波和 EMI 达到项目要求。
- 失败处理：无波形/负载验证时不得声明电源 PCB 完成性能验证。

## PPEM-004：接地、机壳、屏蔽和接口泄放

- 触发条件：外部连接器、屏蔽线、机壳、保护地、ESD/浪涌器件或共模滤波。
- 必须执行：保护器件靠近入口并提供短宽泄放到适当机壳/地；定义屏蔽端接频率策略；控制信号回流与浪涌回流分离。
- 禁止：ESD 电流先流经内部信号地/敏感区；TVS 远离接口；屏蔽通过长细尾线；机壳地连接由随机安装螺钉决定。
- 必需证据：泄放路径、结构接地点、回流阻抗分析、原理图/PCB 和 ESD/EFT/浪涌测试。
- PASS 条件：干扰能量在入口闭合，不穿越敏感区域，正常通信和安全接地满足要求。
- 失败处理：结构/接地事实未知时系统 EMC 结论保持阻塞。

## PPEM-005：串扰、边沿与 EMI 控制

- 触发条件：快速边沿、高频、长并行、时钟、开关节点或 EMC 整改。
- 必须执行：通过间距、相邻参考层、缩短并行、控制边沿/驱动、端接和回流减小耦合；优先定位源-路径-天线而非盲加器件。
- 禁止：只按信号频率忽略边沿；无证据铺地过孔/屏蔽罩；用大串阻破坏时序；整改后不回归功能和温升。
- 必需证据：关键耦合对、场/时域分析、近场/预扫/正式报告、整改前后对比和功能回归。
- PASS 条件：发射/抗扰满足适用限值且功能无回退，整改机理和适用范围明确。
- 失败处理：预扫结果不得冒充认证；失败保留频点、模式、线缆和配置。

## PPEM-006：热布局、铜扩散与温度测量

- 触发条件：功率器件、热焊盘、密闭外壳、热点或环境温度变化。
- 必须执行：从器件损耗/热阻/环境/气流/外壳建立热路径；热过孔按孔铜和工艺设计；温敏器件避开/靠近热源需符合测量目的。
- 禁止：只扩大顶层铜却无跨层/外壳路径；热过孔吃锡未考虑；用开盖实验代表密闭产品；用热像表面温度直接等同结温。
- 必需证据：损耗和热模型、铜/过孔/结构、发射率/测点说明、稳态和瞬态温度。
- PASS 条件：最坏环境下结温/表面温度有余量，热不会破坏精度、寿命、焊点或用户安全。
- 失败处理：无最终外壳/负载时结果标预验证，禁止最终热放行。

## PPEM-007：安规间距、槽、涂覆与板边

- 触发条件：PCB 包含高压、隔离、用户可触、安全边界或涂覆/灌封依赖。
- 必须执行：把原理图推导的电气间隙/爬电录入规则；检查铜、焊盘、过孔、丝印、测试点、安装件、板边、开槽和制造公差；涂覆只按标准允许条件计入。
- 禁止：只测标称 CAD 距离；忽略孔壁/元件本体/焊锡尖峰；未验证涂覆工艺就降低距离；普通 DRC 默认值代替安规规则。
- 必需证据：标准推导、EDA 规则、最小距离报告、机械/制造公差和适用耐压/检查报告。
- PASS 条件：所有边界在最坏公差下满足要求，规则覆盖所有层和对象，豁免经批准。
- 失败处理：任一标准输入未知时禁止制造和认证放行。

## PPEM-008：DFM、装配与可测试性

- 触发条件：PCB 准备投板、拼板、贴装、测试或维修。
- 必须执行：核对最小工艺、阻焊桥、钢网、器件间距、极性/Pin1、可贴装性、工艺边、基准点、测试点、探针可达、返修空间和清洁要求。
- 禁止：只通过电气 DRC 就认定可制造；测试点直接挂在高速/敏感节点而不评估；位号/极性在装配图不可读。
- 必需证据：目标板厂/贴片厂规则、DFM 报告、3D/装配检查、测试覆盖和批准偏差。
- PASS 条件：制造/装配/测试工艺均有明确能力窗口，无关键不可达或不可检验对象。
- 失败处理：目标工厂未确定时只能按候选能力预审，不得正式投产。

## PPEM-009：制造输出和独立回读

- 触发条件：生成 Gerber/ODB++、钻孔、IPC-2581、BOM、PnP、装配图或制板说明。
- 必须执行：从锁定原生版本生成；检查层、单位、零点、极性、孔类型、板框、版本、坐标、面和旋转；用独立查看器回读并生成逐文件哈希。
- 禁止：手工混用不同导出批次；只检查文件存在；修改导出文件而不回写权威源；忽略空层/重复层/错单位。
- 必需证据：生成配置、输出清单/大小/哈希、独立回读截图/报告和原生基线哈希。
- PASS 条件：输出完整、一致、可回读，BOM/PnP/装配与 PCB 位号和变体匹配。
- 失败处理：任何错层/错孔/错坐标/版本冲突均使整批输出 FAIL，重新从权威源生成。

## PPEM-010：PCB 制造完成门禁

- 触发条件：准备发送板厂/贴片厂或声明制造包完成。
- 必须执行：确认 ERC/DRC、未布线、规则、安规、DFM、BOM/变体、制造回读、哈希和批准状态。
- 禁止：以模拟 DRC、旧报告、ZIP 可打开或单个文件正确代替完整制造验证。
- 必需证据：当前原生设计、原始报告、制造清单、回读结果、waiver 和责任人批准。
- PASS 条件：全部强制门禁通过且没有关键 BLOCKED；真实 EDA/工厂条件未验证时维持 RC。
- 失败处理：隔离错误制造包，禁止继续采购/生产，不得原地手改后无版本重发。
