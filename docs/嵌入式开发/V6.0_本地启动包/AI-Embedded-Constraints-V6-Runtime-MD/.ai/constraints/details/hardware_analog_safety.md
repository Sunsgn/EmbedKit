# 硬件模拟、测量、保护与安全原子约束

## HAS-001：模拟信号链与动态范围

- 触发条件：新增/修改传感器、放大、滤波、ADC/DAC、参考或模拟输入输出。
- 必须执行：建立传感源到数字量的完整链路，列出最小/最大/故障输入、共模、增益、偏置、带宽、源阻抗、建立时间和各级余量。
- 禁止：只按标称输入设计；忽略共模/输出摆幅/输入偏置；让保护器件在正常范围显著影响精度。
- 必需证据：链路框图、逐级范围计算、器件曲线、原理图和端点/故障点测量。
- PASS 条件：正常全量程不削顶，故障输入不越额定，ADC/算法可区分有效、饱和和断线状态。
- 失败处理：源范围或参考未知时禁止确定增益和阈值。

## HAS-002：误差、不确定度与温漂预算

- 触发条件：功能涉及精度、阈值、计量、校准或跨温度一致性。
- 必须执行：纳入传感器、参考、阻容容差、增益/偏置、温漂、噪声、量化、非线性、布局寄生、老化和校准残差；说明最坏值或 RSS 方法。
- 禁止：只引用 ADC 位数或单器件典型精度；把校准后单点准确当全量程/全温准确。
- 必需证据：误差预算表、数据手册版本、校准方法、独立验证点和温度/批次数据。
- PASS 条件：总误差/不确定度满足项目限值并保留规定余量，主要贡献项可追溯。
- 失败处理：缺关键误差项时只能报告预算不完整，不得宣称精度通过。

## HAS-003：ADC 采样、驱动与抗混叠

- 触发条件：ADC 通道、采样率、采样时间、多路切换、DMA 或前端滤波变化。
- 必须执行：按采样电容和源阻抗验证建立误差；确定参考驱动、通道切换稳定、采样率、模拟带宽和抗混叠；高阻源必要时缓冲。
- 禁止：默认延长采样时间即可解决全部问题；多路切换后直接使用首样而无验证；数字平均替代抗混叠滤波。
- 必需证据：ADC/前端模型、计算、通道顺序、原始码流、静态/动态/串扰测试。
- PASS 条件：全通道、最坏源阻抗和采样率下建立/噪声/串扰满足预算，无不可识别混叠。
- 失败处理：参考或源模型未知时保持测量结论 UNKNOWN。

## HAS-004：运放、比较器与参考电路

- 触发条件：使用运放、比较器、基准、跨阻、桥式或有源滤波电路。
- 必须执行：核对供电、输入共模、输出摆幅、GBW、压摆率、稳定性、输入偏置/噪声、容性负载和启动；比较器定义滞回和输入过驱恢复。
- 禁止：只在直流典型点验证；忽略轨到轨限制；在无稳定性分析时任意增大输出电容；比较器输入停留阈值附近无滞回。
- 必需证据：最坏工作点、环路/滤波计算、仿真边界、示波器波形和温压测试。
- PASS 条件：正常和瞬态均不饱和/振荡，建立时间和误差满足需求，失效进入可诊断状态。
- 失败处理：模型不足时需要样机测量，仿真不能单独放行。

## HAS-005：输入保护、ESD/EFT/浪涌与误接

- 触发条件：外部连接器、长线、用户可触接口、工业/车载环境或故障输入。
- 必须执行：根据项目环境选择威胁等级；计算限流、钳位残压、能量、脉冲功率、寄生电容和后级注入；定义保护器件失效模式。
- 禁止：只按 TVS 标称电压选型；忽略动态电阻和布局回路；保护地回流穿过敏感地；用软件过滤替代硬件额定保护。
- 必需证据：适用标准/环境、器件曲线、钳位/能量计算、布局约束、预扫或实验室原始报告。
- PASS 条件：被保护器件端最坏应力低于允许值，正常信号性能不被破坏，测试后功能/数据符合判据。
- 失败处理：测试条件不足时标预验证或 NOT_RUN，不得声明正式抗扰通过。

## HAS-006：隔离、高压、爬电与电气间隙

- 触发条件：涉及市电、高压、隔离、患者/用户可触、安全特低压边界或高能系统。
- 必须执行：从适用标准、工作/浪涌电压、过压类别、污染等级、材料组、海拔和绝缘类型推导距离与器件等级；核对隔离电源和跨域信号。
- 禁止：使用“常用 3 mm/6 mm”等固定数字；铜皮/测试点/安装件跨越隔离边界；软件控制作为唯一安全隔离。
- 必需证据：标准条款、计算/表格、原理图/PCB 边界、关键件证书和适用耐压/绝缘测试。
- PASS 条件：所有跨界对象满足推导值及制造公差，关键件和测试与认证配置一致。
- 失败处理：任一标准输入未知即 `BLOCKED`，禁止制板/认证放行。

## HAS-007：接地、屏蔽与模拟数字边界

- 触发条件：模拟/数字/RF/功率混合、屏蔽、机壳地、保护地或长线接口。
- 必须执行：按电流回流而非名称划分地；确定机壳/保护/信号地连接点、共模路径、屏蔽端接和跨域器件；敏感参考避开高 di/dt 回流。
- 禁止：机械分割地平面导致高速信号跨缝；随意单点/多点接地；屏蔽尾线过长；把所有噪声问题归因于“地不干净”。
- 必需证据：回流路径图、频率/电流分析、原理图和布局约束、噪声/共模/EMC 测量。
- PASS 条件：每个信号存在连续低阻回流，保护/浪涌路径不穿过敏感域，接地方案与结构一致。
- 失败处理：结构/线缆未知时记录接口边界，不能完成系统 EMC 结论。

## HAS-008：温升、降额和故障能量

- 触发条件：功率器件、电阻、保险、连接器、线圈、加热或可能短路的电路。
- 必须执行：按最坏 RMS/峰值/占空比计算损耗和结温；考虑环境、铜箔、外壳、邻近热源和器件降额；分析开路/短路/卡死故障能量。
- 禁止：仅按室温手摸或标称功率；忽略脉冲 SOA；用 PCB 铜皮作为未验证保险；超过连接器单 Pin 额定。
- 必需证据：损耗/热阻/SOA 计算、热像/热电偶、极限负载和保护动作记录。
- PASS 条件：最坏结温/表面温度和材料额定满足项目规则，单故障不产生不可接受危险。
- 失败处理：热边界未验证时禁止提高功率或缩小器件/铜面积。

## HAS-009：安全输出、联锁与失效方向

- 触发条件：阀、继电器、电机、加热、高压、燃气、制动或其他危险执行器。
- 必须执行：定义断电/复位/通信丢失/MCU 卡死/驱动短路时的安全态；关键联锁具备需求规定的独立性、诊断和故障覆盖。
- 禁止：仅依赖软件初始化保证安全；使能脚悬空；单点故障可持续危险输出而无硬件限制；AI 未获授权操作真实危险设备。
- 必需证据：安全需求、失效分析、原理图、上电/掉电/故障注入和独立保护测试。
- PASS 条件：所有规定故障进入或维持安全态，诊断覆盖及残余风险经有权角色批准。
- 失败处理：安全态、极性或限值未知时阻止输出和放行。

## HAS-010：模拟与安全完成门禁

- 触发条件：模拟、测量、保护、隔离或危险控制设计准备完成。
- 必须执行：交付信号链、误差/热/保护计算、原生设计、ERC、布局约束、样机与未执行测试清单。
- 禁止：用仿真、典型值、单点测量或内部预扫冒充正式全条件验证。
- 必需证据：当前版本计算、报告、波形、设备/仪器身份和批准 waiver。
- PASS 条件：所有适用预算和安全门禁满足，验证层级准确，无关键 UNKNOWN/CONFLICT。
- 失败处理：保持 `PARTIAL/BLOCKED/NOT_RUN`，禁止采购、制板、危险运行或认证声明。
