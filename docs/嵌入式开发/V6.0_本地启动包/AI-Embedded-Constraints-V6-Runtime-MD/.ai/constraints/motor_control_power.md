# 电机控制、功率电子与执行器详细约束

## MOTOR-001：适用范围与危险边界

适用于有刷/无刷直流、步进、PMSM/感应电机、逆变器、继电器、电磁阀、加热和其他高能执行器。开始前取得母线、电机/负载、功率级、传感器、控制模式、速度/转矩/温度范围、制动、安全状态和机械风险。真实旋转、高压、大电流或加热测试必须有授权、隔离、限能和急停。

- 区分控制命令、功率使能和独立硬件保护，软件初始化不得提前使能功率输出。
- 定义复位、上电、通信丢失、传感故障、软件卡死和掉电时的安全状态。
- 无负载、台架和实际负载的结论等级分开，禁止外推。

## MOTOR-002：功率级、栅极与保护

- 核对开关器件电压/电流/SOA、栅极驱动、电源、死区、传播延迟、米勒效应、反向恢复和热路径。
- 上下桥互锁必须由可靠硬件/定时器机制保证，禁止仅靠两个普通 GPIO 顺序避免直通。
- 过流、短路、过压、欠压、过温和失速保护的阈值、响应、锁存/重试和安全状态来自设计要求。
- 故障输入路径要能在软件失控时关闭输出；软件收到故障后先保持安全状态再诊断，不能自动无限重启功率级。

## MOTOR-003：PWM、ADC 与控制时序

- PWM 频率、中心/边沿对齐、极性、互补、死区、更新点和禁用电平与功率级一致。
- ADC 触发相对 PWM 的位置、采样时间、放大器建立、blanking 和多通道顺序明确；异步采样不得用于需要相位一致的电流环。
- DMA/中断优先级和控制计算最坏执行时间必须满足控制周期，更新寄存器采用安全的影子/同步机制。
- 时钟、计数器溢出和频率变化后重新验证 PWM、采样和保护时序。

## MOTOR-004：传感、估算与标定

- 电流、电压、位置、速度、温度传感链建立单位、方向、偏置、增益、范围、带宽、噪声和饱和模型。
- 上电偏置校准必须确认输出关闭和输入稳定，校准失败不得继续闭环使能。
- 编码器/Hall/反电动势方向、极对数、相序和机械零位通过低能测试验证；禁止用错误相序直接高功率试转。
- 无传感器估算的启动、低速、反转、负载突变和失锁检测需单独验证。

## MOTOR-005：状态机与命令管理

- 使用明确的禁用、自检、预充/准备、对准、启动、运行、制动、故障和恢复状态；所有迁移有守卫、超时和非法事件动作。
- 速度/转矩/位置命令做范围、变化率、方向、来源和当前状态检查；通信帧合法不等于允许执行。
- 模式切换和正反转必须控制斜坡、能量和机械冲击，不得瞬时改变高能命令。
- 停止区分正常减速、自由滑行、动态/再生制动和紧急关闭，并与母线吸收能力匹配。

## MOTOR-006：控制算法与数值安全

- 控制环周期、带宽、增益、限幅、抗积分饱和、滤波和离散化方法记录来源与适用范围。
- 定点/浮点实现检查缩放、溢出、量化、除零、NaN 和饱和；仿真参数不得未经目标量程验证直接部署。
- 级联环路、前馈、解耦和观测器的采样/更新顺序明确，调参必须保存版本和基线数据。
- 优化不能以关闭保护、扩大限幅或隐藏振荡换取响应速度。

## MOTOR-007：台架测试、故障注入与热

- 按低电压/限流、无负载、受控负载、额定和边界逐级测试，每级设停止条件和急停验证。
- 同步采集母线、电流、PWM、位置/速度、温度、故障和控制状态；软件日志不能替代示波器/功率分析。
- 测试堵转、开相、传感断开/冻结、通信丢失、欠压/过压、过温和再启动中的适用项。
- 长期负载验证器件结温、电机温升、母线纹波、效率和保护裕量；短时运转不能证明热稳定。
- 测功机、负载、转矩/速度传感器、电流探头和功率分析仪记录校准、带宽、采样与机械安装；控制器内部估算不能替代独立台架测量。

## MOTOR-008：证据、验收与失败门禁

证据包括功率级/电机/负载版本、保护阈值来源、PWM/ADC 波形、控制周期、传感校准、状态迁移、台架原始数据、热结果和故障恢复。没有独立关断、直通风险未关闭、方向/相序未知、保护未实测或急停不可用时禁止真实高能测试和发布；仿真或空载通过不能证明额定负载安全。
