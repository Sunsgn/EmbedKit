# 软硬件与全栈集成详细约束

## INT-001：适用范围与集成基线

适用于引脚、电源域、总线、传感换算、硬件版本、固件/配置、设备、测试、生产和现场维护之间的契约。开始前锁定原理图/PCB/BOM、接口控制文件、软件提交/固件哈希、配置版本、设备 ID、工装和测试版本；不同基线证据不得混合。

## INT-002：Pin、外设和电气契约

- 建立逐信号映射：网络名、器件/Pin、MCU Pin/复用、方向、有效电平、上下拉、默认/复位/睡眠状态、电压域、驱动能力、软件符号和所有者。
- 对照原理图、Pinmux 生成配置、驱动初始化和运行读回；任一来源冲突标 `CONFLICT`，禁止选择“看起来正确”的一项。
- 共享/复用 Pin 明确各启动阶段、模式切换、互斥和安全过渡；输出使能前先验证电源域及外部器件状态，防止争用和反灌。
- 中断极性、触发方式、消抖、唤醒和清除语义必须软硬件一致；只验证 GPIO 电平不能证明中断路径正确。

## INT-003：总线与通信契约

- UART/I²C/SPI/CAN/USB/网络接口表包含物理层、拓扑、速率/模式、地址/ID、端序、帧上限、终端、超时、重试、错误恢复和资源所有者。
- 示波器/逻辑分析仪证据与软件日志使用同一时间基准或关联标记；只看一侧日志不得断言线上实际波形/帧正确。
- 验证断线、短暂干扰、从机复位、主机重启、总线忙、错误帧和恢复；通信失败不得阻塞本地安全路径。
- 协议版本与硬件能力通过显式能力/版本字段匹配，不能由产品显示名称推断。

## INT-004：ADC、传感、控制和误差预算

- 建立“物理量→传感器→模拟前端→ADC 原码→校准→工程量→判定/控制”的完整链，逐段声明单位、范围、增益、偏置、符号、分辨率和饱和。
- 误差预算包含器件容差/温漂、参考、噪声、量化、采样、布线、校准和算法；说明最坏值或统计合成方法。缺输入为 `UNKNOWN`，不得填经验精度。
- 使用已溯源激励点覆盖零点、中点、满量程、上下边界、超量程和温度条件；仿真数值不能替代模拟链路实测。
- PWM/DAC/执行器验证命令值、实际波形/输出、负载响应、安全禁用和故障状态；危险执行器需额外授权。

## INT-005：启动、时序、复位和功耗模式

- 联合时序列出各电源、复位、时钟、Boot、外设就绪、总线初始化、任务启动和首次输出；用测量验证关键相对时间。
- 覆盖慢上电、快速重上电、棕断、外设晚就绪、看门狗复位、软件复位和局部模块复位；禁止用单一正常上电证明全部路径。
- 睡眠/唤醒验证电源域、Pin 状态、唤醒源、时钟恢复、外设重初始化和首次通信；功耗测量注明模式、仪器带宽和采样窗口。

## INT-006：版本、配置和混合组合

- 每个可交付组合记录硬件版本、BOM 变体、Bootloader、应用、协议、配置/NVM schema、工装和生产参数版本。
- 兼容矩阵逐组合标 `SUPPORTED/REJECTED/NOT_TESTED` 及证据；“向后兼容”必须由旧硬件/旧数据/混合版本测试证明。
- 硬件差异通过板级描述/适配器集中处理；禁止业务代码散布版本条件。无法识别硬件版本时进入安全兼容或拒绝模式，不得猜测。
- NVM/配置升级有迁移、掉电和回退；旧固件读到新数据、新固件读到旧数据的行为分别验证。

## INT-007：Bring-up 与问题隔离

- 按电源→时钟/复位→调试口→最小固件→单外设→总线→应用的顺序集成，每步建立可回退已知好基线。
- 故障采用替换变量法区分硬件、固件、配置、线缆、工装和环境；一次只改变一个关键变量并记录前后证据。
- 不得为让软件运行而随意改变引脚、电平、时序或关闭保护；发现硬件缺陷需建立正式偏差/返修并标识样机。

## INT-008：生产、测试与现场闭环

- 设计接口映射到 ICT/FCT/HIL 测试点、命令、阈值和追溯字段；开发调试命令不得无认证进入发布固件。
- 每台设备关联序列号、硬件/BOM、固件/配置、校准、测试结果和返修；人工录入必须校验并可审计。
- 现场日志包含兼容版本、复位原因、关键错误和有限原始证据；远程更新前验证设备身份、硬件和回退能力。

## INT-009：验收、证据与失败门禁

证据包括基线清单、Pin/电气/总线契约、误差预算、联合时序、兼容矩阵、仪器原始文件、设备/固件身份、测试和问题隔离记录。任何 Pin/电压冲突、错误安全状态、误差超预算、关键混合版本未测或证据版本不匹配都禁止集成/生产/发布放行；仅软件模拟不能证明全栈通过。
