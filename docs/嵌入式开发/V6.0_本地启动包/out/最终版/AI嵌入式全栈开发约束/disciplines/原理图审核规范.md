# 原理图审核规范

本规范定义AI进行原理图设计辅助和审核时的强制输入、检查项、证据及输出。器件、电气计算和硬件通用约束以同目录`电子硬件工程总规范.md`为准。

## 1. 最小输入

审核前确认原理图源文件或PDF、网表、BOM、器件数据手册版本、电源树、接口定义、设计输入、板卡版本和ERC结果。只有图片或PDF时必须声明无法可靠核对网络连接、隐藏电源脚、封装映射和属性字段的覆盖盲区。

输入不足时可以输出初审风险，但不得标记完整审核`PASS`。具体芯片、电压、阈值、封装、引脚和保护等级不得由经验猜测。

## 2. 强制检查范围

### 2.1 电源与地

- 核对所有电源脚、地脚、模拟电源、参考电压和裸露焊盘，不得只检查可见引脚。
- 按最坏负载、动态电流、外部供电和裕量检查电源树；检查稳压器输入输出范围、压差、环路稳定条件、热耗散和反向灌电。
- 核对去耦和储能的数值、耐压、介质、有效容值、数量、位置要求及回流路径。
- 检查上电、掉电、Brown-out、复位、电源时序、未供电IO反灌和多电源域隔离。

### 2.2 时钟、复位与启动

- 晶体/振荡器型号、频率、负载电容、ESR、驱动等级和器件建议必须有数据手册依据。
- 复位脉宽、上拉/下拉、监控芯片、调试复位和外部干扰路径必须明确。
- Boot Strap、模式脚和下载脚必须检查上电采样时刻、默认态、外部负载冲突及量产可访问性。

### 2.3 数字与通信接口

- 核对电压域、方向、容限、默认电平、上拉下拉、开漏/推挽、扇出、边沿和电平转换。
- I²C按总线电容、目标速率、漏电和器件灌电能力推导上拉范围；不得直接套用经验阻值。
- SPI/UART/CAN/USB/Ethernet等核对拓扑、端接、共模范围、保护器件、连接器顺序、热插拔和故障状态。
- 核对原理图网络名、连接器Pin号、器件Pin号、封装Pad号和软件资源命名的一致性。

### 2.4 模拟、传感与功率

- 检查输入范围、共模、源阻抗、偏置、采样保持、抗混叠、增益、饱和、误差和温漂预算。
- 检查传感器激励、参考、校准路径、开短路检测和安全失效方向。
- 功率器件核对额定值降额、SOA、栅极驱动、死区、续流、吸收、浪涌、短路及热路径。

### 2.5 安全、保护与可测性

- ESD、浪涌、反接、过流、过压、欠压、隔离、爬电和电气间隙必须依据适用环境及标准，不得自行宣布合规。
- 调试口、下载口、测试点、关键电源和总线必须具有可测路径；危险节点必须定义安全测量方式。
- 检查未连接引脚、悬空输入、重复网络名、跨页连接、器件可采购性、MPN及封装匹配。

## 3. 审核方法

1. 建立电源树、接口表和关键器件清单。
2. 对每个关键器件按数据手册逐脚核对，记录资料版本及页码。
3. 将ERC结果逐项分类，不得以“有意忽略”批量关闭。
4. 对电源、上拉、分压、滤波、热和保护给出输入、单位、公式、裕量与最坏条件。
5. 将原理图网络与软件引脚/接口矩阵双向核对；不涉及软件时标记不适用。

## 4. 输出合同

每个发现必须包含：问题ID、页码/器件/引脚/网络、问题描述、证据来源、风险等级、可能后果、整改建议、验证方法、责任专业和状态。

结论分为`CONFIRMED_ERROR`、`RISK`、`IMPROVEMENT`、`INSUFFICIENT_INFORMATION`和`NOT_REVIEWED`。只有范围内所有必审项均有证据、关键计算成立、阻断项关闭且ERC经过解释，才能给出审核`PASS`。

## 5. 原理图设计交付的具体方法

### 5.1 从需求到电路
1. 建立功能块图和接口控制表，明确每个功能的输入、输出、供电、工作模式、异常状态和验证点。
2. 建立电源树：输入源范围、保护、各电源轨、时序、最大/脉冲负载、关断状态和反灌路径。
3. 建立MCU最小系统：供电脚/地脚、去耦、参考、复位、时钟、启动配置、调试下载和未使用引脚处理。
4. 按接口逐个设计电平匹配、驱动、终端、隔离、保护和连接器；对外接口必须考虑开短路、反接、热插拔和线缆故障。
5. 按传感器链路设计激励、模拟调理、滤波、ADC参考、校准和诊断路径。
6. 对驱动负载设计开关器件、栅极/基极驱动、续流/吸收、过流/过温和默认安全态。
7. 形成原理图后导出网表，进行符号Pin、器件Pin、封装Pad三方映射核对。

### 5.2 常用计算必须有边界
- I²C上拉：由总线电容`C_bus`、上升时间上限`t_r`和低电平灌电流能力共同约束。近似下限`R_p,min=(V_DD−V_OL,max)/I_OL`；近似上限`R_p,max=t_r,max/(0.8473×C_bus)`（适用一阶RC上升沿模型）。还需核对器件输入漏电、并联上拉、线缆和电压域；超出可行区间应调整总线电容/速率/缓冲器，而非随意取中间值。
- LED限流：`R=(V_supply−V_F−V_driver)/I_LED`，按供电最大/最小、LED正向压降范围、驱动压降和功耗分别计算最坏电流与亮度下限。
- 分压：`V_out=V_in×R2/(R1+R2)`，把电阻容差、输入范围、负载、ADC输入和保护漏电纳入最坏误差。
- RC截止频率`f_c=1/(2πRC)`只描述理想一阶网络；源阻抗、负载、容差和多级耦合需纳入。

### 5.3 ERC与网表
ERC规则集需记录EDA名称/版本、规则配置哈希、例外和批准人。逐项审查未连接、电源标志、驱动冲突、悬空输入、跨页标签、隐含电源脚和多单元器件。ERC通过只证明规则集未报告对应违规，不证明功能正确。进入PCB前必须核对网表器件数、Pin映射、未连接网络和BOM身份。

### 5.4 输出物
设计任务输出原生原理图、PDF、网表、BOM初稿、电源树、接口控制表、关键计算、器件数据手册引用、ERC报告、问题清单和版本哈希。只有PDF/截图时注明不能验证原生对象属性和网表一致性。
