# 机械、热与可靠性规范

本专业可独立用于结构、装配、热和环境可靠性分析。电子硬件只提供功耗、边界和接口，不替代本专业判定。

- 输入必须包含结构版本、材料、尺寸与公差、安装方向、连接器/线束、质量、冲击振动、温湿度、防护、散热条件和任务剖面。
- 公差分析覆盖极限组合、装配顺序、紧固、形变、磨损、热膨胀和维护空间；名义3D无干涉不能证明可装配。
- 热分析使用真实功耗、接触热阻、界面材料、气流、辐射和环境边界；模型记录网格、材料、边界、求解器及相关性验证。
- 温度结论必须覆盖稳态、瞬态、启动、峰值负载和故障；结温、表面温度、材料和电池限值分别判定。
- 可靠性计划从任务剖面和失效机理推导，不套用固定温度、振动或寿命时长；样本量、应力、失效判据和统计方法必须明确。
- 机械、热或环境变更必须传播到PCB禁布、高度、连接器、天线、传感器、校准和测试。
- 仿真通过不能替代样机测温、装配、冲击振动或环境试验；无实物证据时保持`NOT_RUN/UNAVAILABLE`。

## 可执行作业方法

### 结构与公差
1. 锁定零件图、3D模型、材料牌号、表面处理、基准体系、尺寸公差、GD&T、紧固件和装配顺序。
2. 对关键尺寸链建立方向和基准一致的尺寸链表达式。最坏情况线性叠加可用`T_wc = Σ|a_i|T_i`；统计法仅在分布、独立性和过程能力有依据时使用，不能用RSS替代安全关键的最坏情况分析。
3. 检查板边/拼板工艺边、壳体、螺柱、线束弯曲半径、连接器插拔、工具可达、密封压缩量和维修空间。
4. 将干涉、装配力、紧固扭矩、密封和变形风险记录到问题单，并用实物装配复核。

### 热设计
建立功耗清单和热路径：热源→封装/结构→界面材料→散热体/空气→环境。稳态初估可用`ΔT = P·Rθ`，但必须说明热阻来源、边界条件及适用范围；多热源、瞬态和强耦合场景使用经相关性验证的热模型。分别校核芯片结温、电池温度、塑料/胶黏剂温度和用户可触及表面温度。

### 可靠性验证
依据任务剖面定义温度循环、恒温、湿热、振动、冲击、防护、跌落、寿命和运输试验。每项记录样本量、应力等级、持续时间、通电状态、监测量、失效判据、停测条件和统计方法。加速试验必须有失效机理和加速模型依据。

### 输出与门禁
输出尺寸链、公差分析、热预算/模型、关键材料清单、装配风险、试验计划和实测记录。CAD无干涉、仿真收敛或单台样机通过均不能单独证明批量装配和可靠性通过。
