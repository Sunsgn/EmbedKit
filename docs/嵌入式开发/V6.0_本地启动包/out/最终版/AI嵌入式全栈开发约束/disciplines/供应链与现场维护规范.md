# 供应链与现场维护规范

本专业可独立用于器件生命周期、变更通知、现场诊断、RMA和退役管理。

- 物料使用完整MPN、制造商、批准供应渠道、生命周期、替代料、PCN/EOL和适用产品版本；模糊料号不能用于采购或追溯。
- PCN、EOL、替代料和可疑批次必须评估电气、封装、固件、校准、制造、认证、库存、现场兼容和回归影响。
- 现场包绑定设备身份、硬件、固件、配置、升级路径、回滚、诊断工具和授权；状态未知的非幂等写入不得自动重放。
- 诊断日志设置大小、速率、轮转和脱敏，能关联时间、复位原因、错误码和关键状态；日志风暴不得导致资源耗尽或掩盖原故障。
- RMA记录症状、环境、版本、复现、拆解、根因、维修、复测、批次关联和纠正预防措施；“换板恢复”不等于根因关闭。
- 现场修复先保护用户数据和可恢复性；远程访问、升级、配置修改和设备控制需要目标确认、最小权限、审计和授权。
- 退役定义密钥撤销、数据清除、固件支持终止、备件、法规和处置要求。

## 可执行作业方法

### 器件生命周期与替代料
每个关键器件建立制造商、完整MPN、封装/温度等级、额定值、生命周期状态、PCN/EOL日期、批准渠道、库存和替代料记录。替代料不能仅按引脚兼容判断；必须比较电气极限、时序、精度、噪声、热特性、启动行为、封装尺寸、认证和供应条件。

### 替代料验证流程
1. 获取原料与候选料正式数据手册、PCN和质量文件。
2. 建立差异矩阵，识别超出原设计裕量的参数。
3. 评估原理图、PCB封装、固件驱动、校准系数、EMC、安全、制造和认证影响。
4. 制作样件并执行针对性电气、环境、通信、精度和可靠性回归。
5. 经工程、质量和供应链授权后更新批准物料清单及适用产品版本。

### 现场维护与RMA
现场升级包绑定设备身份、硬件、当前固件、目标固件、配置、签名、升级路径、回滚路径和操作授权。升级前检查供电、通信和存储空间；中断后按设备状态机恢复，不得盲目重复写入。RMA记录原始症状、环境、日志、复现条件、版本、批次、根因、纠正措施和复测证据。

### 退役与支持
定义安全更新支持期、漏洞响应、备件期限、密钥撤销、用户数据清除、云端服务终止、法规记录保存和电子废弃物处置要求。
