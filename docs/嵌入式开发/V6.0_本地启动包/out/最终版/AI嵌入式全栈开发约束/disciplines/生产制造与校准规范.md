# 生产制造与校准规范

本专业可独立用于试产、量产、工装、烧录、校准和追溯设计；任何生产写入或放行动作仍需明确授权。

- 制造基线绑定硬件、BOM、替代料、固件、Bootloader、配置、校准算法、工艺文件、工装和测试程序版本。
- DFM/DFT覆盖拼板、工艺边、钢网、可制造间距、器件方向、测试点、编程口、夹具接触、安全隔离、返修和防错。
- 工装和仪器具有稳定ID、版本、校准状态、量程、精度、维护周期和自检；失校结果必须隔离并评估影响批次。
- 校准规定标准器、环境、预热、采样、拟合、接受限、独立验证点、系数格式、写入地址、写保护、回读和失败恢复；只保存最终系数不足以追溯。
- 每台产品记录序列号、批次、关键物料、硬件、固件、配置、校准、测试运行ID、结果和返修历史。
- 生产失败不得靠无限重试、放宽阈值、跳站或人工改结果放行；返修后重新执行受影响站点和回归。
- 量产切换、批量烧录和永久写入属于非幂等动作；身份或状态未知时不得自动重放。

## 可执行作业方法

### 工艺基线与工装
建立产品配置基线：硬件版本、BOM/替代料、固件/Bootloader、配置、校准算法、烧录文件、工装、仪器、工艺参数和测试程序。工装需有防错定位、接触检查、量程检查、权限控制和校准状态检查。工装或程序变更必须进行影响分析和首件确认。

### 测量系统能力
确认标准器证书有效、量程覆盖、分辨率和不确定度满足测量需求。测量结果应考虑标准器、分辨率、重复性、温度、压力源稳定性、泄漏、连接和操作者等分量。独立且适用时可用`u_c = sqrt(Σu_i²)`合成标准不确定度，扩展不确定度`U = k·u_c`；相关分量需考虑协方差，不能机械套用平方和。

### 校准执行
1. 核对设备序列号、硬件/传感器批次、固件和校准状态。
2. 检查工装自检、标准器状态、环境、预热和稳定判据。
3. 按批准点位执行升程/降程和重复测量，保存原始读数，不覆盖原始数据。
4. 按已批准模型拟合，区分拟合点和独立验证点；报告残差、最大误差、重复性、迟滞、温漂和不确定度。
5. 写入前保存原系数；写入后回读、校验CRC/版本/范围，并进行断电保持和独立验证。
6. 超差、数据缺失、写入回读不一致或标准器失效时隔离设备/批次并启动不合格处理。

### 过程能力与追溯
关键工序定义CTQ、抽样方案、控制限来源、SPC方法和反应计划。GR&R研究应按测量对象、操作者、设备和重复次数设计；不能只凭单次重复测量宣称测量系统合格。每台设备关联序列号、批次、原始数据、算法版本、系数、标准器ID、操作者、时间、复测和返修历史。
