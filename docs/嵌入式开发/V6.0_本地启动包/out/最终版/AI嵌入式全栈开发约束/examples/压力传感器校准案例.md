
# 案例：压力传感器校准（流程示例，非生产工艺）

## 1. 输入
确认传感器型号/批次、量程、温度范围、目标精度、标准器证书、压力源、温箱、采集硬件、固件版本和批准校准规范。

## 2. 测量系统
先验证标准器量程、准确度/不确定度、压力稳定、泄漏、温度均匀性、预热和重复性。测量系统能力不足时停止精度放行。

## 3. 点位与模型
按批准规范选择压力/温度点、升降程和重复次数。分开拟合点与独立验证点。模型选择须防止过拟合，并报告残差、最大误差、迟滞、重复性、温漂和不确定度。

## 4. 写入与回读
写入前读取并保存原校准系数；经授权后写入，回读校验CRC、版本、范围和断电保持；使用独立验证点复测。任何失败均隔离设备并保留原始数据。

## 5. 追溯
每台设备绑定序列号、硬件/固件、传感器批次、标准器、环境、原始数据、算法版本、系数、操作者、时间和结果。示例不能替代真实标准器、工艺批准或产品验收。


## RC2案例验收补充（示例流程，数值须由实际项目输入）
### 失败注入与隔离
注入场景：标准器校准证书过期、温箱未稳定、压力连接存在泄漏、拟合验证点超差、写入后回读不一致。任一情况均不得放行该台设备；保留原始数据和原系数。
### 整改与回归
先确认测量系统能力、连接密封、温度均匀性和预热稳定判据；重新采集时区分拟合点与独立验证点。不得通过无依据删除异常点或提高拟合阶数掩盖超差。
### 追溯交付
记录设备序列号、传感器批次、硬件/固件版本、标准器ID/证书、环境、原始数据、算法版本、系数、残差、最大误差、不确定度、写入回读、操作者和复测结果。未在真实设备执行写入回读时标记NOT_RUN。
