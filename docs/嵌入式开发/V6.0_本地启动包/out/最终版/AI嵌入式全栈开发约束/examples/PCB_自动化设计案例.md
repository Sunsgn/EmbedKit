
# 案例：PCB自动化设计（流程示例，非已验证工具能力）

## 1. 输入
原理图原生文件、网表、BOM、封装库、机械板框、拼板工艺边、安装孔、层叠、制造商能力和网络约束。区分产品外形与工艺边，确认拼板边是否属于最终装配外形。

## 2. 解析
从EDA导出网表并核对器件/Pin/Pad映射；解析封装尺寸和极性；对原理图与网表进行版本绑定。仅有PDF或截图时不得进入自动编辑阶段。

## 3. 约束与布局
生成Net Class和规则来源表；先锁定连接器、机械约束、天线/隔离区，再按功能分区。记录每次布局变更及受影响网络。

## 4. 布线与验证
先布关键电源/回流、高速、时钟和敏感模拟，再布普通网络。自动布线完成后检查未连接、回流路径、过孔、长度/偏斜、制造能力和DRC。工具不能自动处理的失败网络必须列出，不得伪造完成。

## 5. 制造回读
导出Gerber/ODB++、钻孔、BOM、坐标和装配资料；使用独立查看器回读板框、层、孔、极性、坐标原点和版本。只有真实运行证据才可升级能力等级。


## 案例验收边界（工具流程示例，未声称真实EDA执行）
### 输入与决策记录
输入至少包括原理图源文件及哈希、网表、BOM、封装库版本、板框/安装孔、层叠、板厂能力、网络分类和禁布区。每项约束记录来源、单位、适用网络及是否经用户确认。
### 失败注入与整改
故障样例：封装Pad编号与符号引脚不一致。预期门禁应在布局前阻断；整改后重新导出网表并核对RefDes/Pin/Pad映射。另对未连接网络、短路、间距、铜到板边和钻孔输出进行故障注入。
### 回归与交付
实际工具验证必须保留EDA名称/版本、工程哈希、ERC/DRC规则集、原始报告、豁免批准、Gerber/钻孔/BOM/坐标输出哈希和独立回读结果。未调用EDA或未回读制造输出时分别标记NOT_RUN，不得称为自动设计完成。
