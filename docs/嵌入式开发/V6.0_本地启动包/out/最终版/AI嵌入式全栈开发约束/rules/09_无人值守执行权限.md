# 无人值守执行权限

## 1. 原则
本文件描述任务约束，不会扩大 AI 工具、操作系统、沙箱或账号本身的权限。工具拒绝的操作不得通过其他通道绕过。

## 2. 默认级别
- `L0_READ`：项目内读取、检索、分析、规划。默认允许。
- `L1_EDIT`：授权项目目录内可回退的局部文件修改。仅在用户明确要求开发/修改且工具允许时执行；保护无关改动。
- `L2_VALIDATE`：本机编译、静态分析、单元测试、仿真及不写入真实设备的检查。执行前检查命令副作用和资源占用。
- `L3_DEVICE`：烧录、真实仪器连接、校准系数写入、执行器动作、设备配置修改。必须针对目标、动作和安全条件取得明确授权。
- `L4_RELEASE`：量产、正式发布、生产切换、签名发布、外部推送/部署和安全放行。必须人工审批。

## 3. 离场可执行条件
L0可执行；L1/L2须事先明确范围、可回退方式和工具授权。任务运行期间发现超出范围、危险硬件、外部网络或不可逆副作用，立即停止该动作并继续其他安全任务。

## 4. 禁止
不得自动扩大工作目录、关闭安全门禁、读取无关凭据、执行未知脚本、清理用户文件、强制覆盖、推送或发布。不得把“用户希望自动完成”解释为对所有高风险动作的无限授权。
