# 跨版本交接与迁移

## 1. 交接包必须绑定版本
每个任务记录规范包版本、结构版本、任务ID、输入锁定标识、工具版本、最近门禁、未完成项、证据索引、工作区状态和禁止重放动作。

## 2. 不自动迁移
升级规范包不得自动改写、转换或删除旧版本 `work/<task-id>/`。新版本读取旧交接包时，先生成迁移分析，列出字段映射、丢失信息、状态语义变化和风险。

## 3. 恢复判定
旧交接包仅可作为历史事实来源。恢复执行前必须重新核对：
- 规范版本和任务状态；
- 输入文件及工作区变化；
- 工具和环境版本；
- 用户授权是否仍有效；
- 证据是否对应当前对象。
无法证明一致时降级为 `BLOCKED` 或重新调查。

## 4. 迁移审批
只有用户明确批准迁移后才生成新交接副本。保留原件、迁移报告、迁移后哈希和执行人/时间记录。不得原位覆盖旧交接包。
