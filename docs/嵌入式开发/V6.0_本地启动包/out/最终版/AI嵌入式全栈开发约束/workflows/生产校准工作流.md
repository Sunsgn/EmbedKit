# 生产校准工作流

## 1. 输入锁定
确认产品/硬件/固件版本、传感器型号与批次、校准范围、温度范围、目标精度、标准器及证书有效期、工装、环境要求、校准软件版本和批准的工艺文件。

## 2. 测量系统确认
确认标准器量程、准确度/不确定度、分辨率、稳定性、校准有效期、连接泄漏、预热、环境均匀性和操作重复性。测量能力不足时停止精度放行，不得通过增加拟合阶数掩盖测量系统问题。

## 3. 校准点设计
根据量程、非线性、温度影响和使用场景制定点位、升降程、重复次数、稳定判据和异常点规则。点位必须覆盖验收范围；拟合点与独立验证点应区分。

## 4. 模型与系数
明确模型类型、输入变量、单位、系数精度、数值范围、拟合方法和防过拟合策略。记录原始数据、剔除理由、算法版本、系数、残差、最大误差和不确定度。不得无依据删除异常点。

## 5. 写入与回读
校准系数写入设备属于受控动作。写入前保存原值和设备身份；按批准流程写入后回读、校验CRC/版本/范围，并验证断电保持。未经明确授权不得写入真实设备或永久存储。

## 6. 验收与追溯
每台设备记录序列号、传感器批次、硬件/固件版本、标准器ID、证书、环境、原始数据、模型、系数、操作者、时间、结果和复测。批次统计与GR&R按项目质量计划执行。

## 7. 失败处理
测量系统异常、泄漏、稳定性不足、数据缺失、系数越界、写入回读不一致或独立验证超差时，隔离设备/批次，保留原始数据，启动不合格处理；不得自动覆盖原系数。
