# AI 嵌入式全栈开发入口

开始或继续任何开发、分析、测试或交付任务前，必须读取 `AI嵌入式全栈开发约束/00-AI嵌入式全栈约束入口.md`，并按其中的索引只加载当前任务需要的专业规范和工作流。

项目连续状态由 AI 自动维护在项目根目录 `.ai-work/PROJECT_STATE.md`。每轮默认只读取文件顶部不超过 4,000 字符的“会话恢复摘要”，再按当前对象定向读取失败方案、已有结论和证据；禁止无条件读取全部历史。用户不负责维护这些记录。

遵守项目内更具体的有效约束和用户当前明确要求，但不得绕过安全、事实、证据、数据保护和授权边界。不要把整个约束包一次性加载到上下文，不要把项目状态、日志或项目专用结论写回通用约束目录。
