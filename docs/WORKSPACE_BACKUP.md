# EmbedKit 工作区备份与恢复

网页进入“数据管理”即可下载或导入版本化 JSON，不需要 Local Agent。备份用于更换浏览器、迁移电脑和恢复常用配置，不代替 Git、工程压缩包、固件发布包或原始测试报告归档。

## 包含内容

- 工程档案中的程序功能、环境需求和资料索引。
- 最多 5000 条测试运行摘要以及最多 500 个工程档案。
- 测试套件；标记为秘密的变量值始终清空。
- 工具收藏与最近使用、串口快捷指令、网络发送历史、学习进度。
- 已脱敏的 ELF、MAP、BIN、HEX 分析摘要。

测试运行只保留状态、步骤、耗时、重试、固件与通信会话摘要，不携带原始日志、实际响应、失败文本和环境中的密码类字段。需要完整验收证据时，应单独导出集成测试 JSON 或 HTML 报告。

## 默认排除

- 源码、编辑器工作区、运行轨迹原文。
- 固件、MAP、ELF 内容和构建日志。
- 绝对构建路径、临时任务 ID 和文件授权令牌。
- AI 密钥、密码、凭据和活动会话。
- 浏览器缓存、调试日志与 Local Agent 状态。

Linux 串口 `/dev/...` 等端点只保存在通信快捷项或测试会话摘要中；导入后仍需用户重新连接真实设备。

## 导入规则

1. 文件总大小最多 16 MiB，单项浏览器配置最多 4 MiB。
2. 只接受 `embedkit.workspace-backup` 版本 1，未知字段不会进入浏览器存储。
3. 页面先显示工程档案、测试记录和本地配置数量及同 ID 冲突数。
4. 用户点击“确认合并”后才写入；同 ID 使用备份内容，其他现有数据保留，不提供清空覆盖。
5. 产品数据库使用单个事务；数据库合并失败时回滚本次本地配置写入。
6. 导入完成后重新进入对应模块即可读取恢复数据，不会自动打开串口、网络连接、工程目录或外部服务。

导入文件属于不可信输入。解析器会重新执行版本、结构、数量、大小、字段白名单和秘密值清理，不应通过手工修改 JSON 绕过界面限制。
