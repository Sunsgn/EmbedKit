# 加解密与签名工具

工具箱的密码工作台用于嵌入式协议联调、测试向量核验和格式转换，所有输入均在浏览器本地处理。

## 支持范围

| 算法 | 能力 | 模式或格式 |
| --- | --- | --- |
| AES | 加密、解密 | ECB、CBC、CTR、CFB、OFB、GCM；128/192/256 位密钥 |
| DES | 加密、解密 | ECB、CBC、CFB、OFB；仅用于遗留兼容 |
| 3DES | 加密、解密 | ECB、CBC、CFB、OFB；双密钥和三密钥，仅用于遗留兼容 |
| RC4 | 加密、解密 | 1–256字节原始HEX密钥；流加密，无IV和填充，仅用于遗留兼容 |
| SM4 | 加密、解密 | ECB、CBC；128 位密钥 |
| SM3 | 摘要、HMAC | 文本、HEX、Base64 输入 |
| SM2 | 加密、解密、签名、验签 | C1C3C2/C1C2C3，裸签名/DER，用户标识 |
| MD5/SHA-1/SHA-256/SHA-512 | 摘要、HMAC | MD5和SHA-1仅用于遗留兼容与结果核验 |

AES-GCM输出为“密文后紧跟128位认证标签”；解密输入使用相同布局。对称算法支持PKCS#7、零填充或无填充，但具体可选项受算法与模式限制。

RC4存在已知安全弱点，平台仅为旧设备、旧协议联调和既有测试向量核验提供兼容能力，不应用于新产品设计。

## 验证与限制

- 页面加载后使用公开已知答案测试验证AES、DES、3DES、RC4、SM3和SM4；任一自检失败时禁止执行对称加解密。
- 对称加解密可填写预期密文或明文进行字节级核对；HEX会忽略常见分隔符和大小写，Base64按解码后的真实字节比较。不一致时报告首个差异字节、双方长度和该位置的字节值。
- AES-GCM使用浏览器Web Crypto；AES/DES/3DES使用`crypto-es`；国密算法使用`sm-crypto`。依赖版本锁定在`package-lock.json`中并进入项目安全检查。
- 单次对称加密或摘要输入上限为16 MiB，SM2输入上限为1 MiB。
- 密钥、IV和私钥默认明文显示，方便联调核对；可随时切换为隐藏显示。密钥、IV、明文、私钥和结果不写入LocalStorage，“清除敏感输入”会清除当前内存状态。
- 该工具用于开发联调和确定性结果核验，不替代HSM、密码卡、生产密钥管理系统或合规认证实现。
