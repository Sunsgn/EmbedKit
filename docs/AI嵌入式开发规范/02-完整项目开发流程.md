# 完整嵌入式项目开发流程

## 1. 流程适用规则

| ID | 条件 | 执行方式 |
| --- | --- | --- |
| C-FLOW-001 | T0-T1，只读或局部修改 | 只执行受影响阶段，列出未触发阶段，不得伪造完整项目交付 |
| C-FLOW-002 | T2，模块或公共接口变更 | 执行需求、详细设计、实现、验证和发布影响分析 |
| C-FLOW-003 | T3-T4，新产品、硬件或系统变更 | 执行全部阶段和门禁；缺失前置事实时停止后续放行 |
| M-FLOW-004 | 任何阶段发现前置事实错误 | 退回对应阶段修正，不得只在末端增加延时、重试或补丁 |

## 2. 阶段输入、动作和退出门禁

| 阶段 | 最小输入 | AI 必须执行 | 可带走的输出 | 退出门禁 |
| --- | --- | --- | --- | --- |
| F0 输入立项 | 版本化项目输入登记 | 校验状态、冲突、假设和 B1-B4 阻塞项 | 输入基线和立项边界 | 对应阶段阻塞项已关闭或明确不进入该阶段 |
| F1 需求 | 已接受的用户场景、环境、约束 | 将功能、失败、资源、安全和兼容要求转成稳定 ID | 需求/未知项/验收表 | 关键矛盾已关闭或显式阻塞 |
| F2 架构 | 已确认需求 | 划分软硬件职责、数据流、控制流、所有者、降级和恢复 | 系统框图、接口表、预算 | 跨域接口有电气和逻辑定义 |
| F3 详细设计 | 架构、数据手册、规则 | 设计状态机、并发、存储、原理图、PCB约束和测试点 | 设计记录、风险清单 | 关键参数有依据，评审问题可追踪 |
| F4 实现/制板 | 已评审设计 | 小步实现，锁定源码、EDA、BOM、配置和制造版本 | 可构建代码或制造包 | 检查通过，恢复路径可用 |
| F5 Bring-up | 样机、限流和测量方案 | 按电源到业务逐层验证，保存原始测量 | 板级记录、缺陷和证据 | 当前层通过后才能进入上层 |
| F6 集成验证 | 可运行软硬件 | 覆盖正常、失败、边界、资源、恢复和长稳 | 测试记录、缺陷、资源实测 | 需求有证据或明确未验证状态 |
| F7 发布/维护 | 验证结果、版本清单 | 生成可追溯发布清单、回退和现场定位信息 | manifest、批准记录、归档 | T4 必须由责任人放行 |

## 3. 需求拆解规则

每项需求至少包含：

```text
需求 ID：稳定且不可复用
触发输入：谁、何时、什么格式和范围
正常输出：可观测且可测量
失败输出：错误分类、最终状态和恢复
资源上限：时间、内存、队列、功耗或空间
兼容范围：旧硬件、旧数据、旧协议和迁移
验证方法：主机、台架、样机、整机或生产
```

| ID | 触发条件 | AI 必须执行 |
| --- | --- | --- |
| M-REQ-001 | 需求包含“快速、低功耗、稳定”等词 | 转成可测指标，无法确定时标记未知并请求范围 |
| M-REQ-002 | 需求涉及外部输入 | 定义格式、单位、边界、无效输入和信任等级 |
| M-REQ-003 | 需求涉及状态变化 | 定义启动、运行、停止、超时、取消、异常、重启和恢复 |
| M-REQ-004 | 需求涉及安全动作 | 定义安全状态、单点故障反应和人工批准边界 |

## 4. 软硬件接口规则

每个接口必须在同一记录中包含：信号/协议名称、电气属性、逻辑语义、方向、时序、默认态、所有者、异常状态、版本和验证点。软件不得只依据变量名猜测硬件语义，硬件不得只依据功能名猜测固件时序。

## 5. 板级 Bring-up 实际顺序

| 步骤 | 进入条件 | 检查内容 | 停止条件 |
| --- | --- | --- | --- |
| B1 无源检查 | 板版和装配明确 | 极性、短路、阻值、焊接和关键网络 | 短路、错件、极性不明 |
| B2 限流上电 | 电源方案和限流值已确认 | 输入电流、各电源轨、纹波、温升 | 过流、异常升温或电压越界 |
| B3 基础启动 | 电源稳定 | 时钟、复位、启动脚、调试口、Boot 日志 | 时钟/复位不满足手册条件 |
| B4 最小固件 | 调试/恢复通道可用 | GPIO、定时、看门狗和故障记录 | 无法恢复或复位原因不明 |
| B5 外设总线 | 引脚和电平已核对 | 中断、DMA、I²C/SPI/UART/CAN 原始证据 | 电平、时序或物理位不正确 |
| B6 系统业务 | 底层分级通过 | 存储、网络、协议、升级和完整业务 | 下层仍存在未关闭故障 |

## 6. 变更传播检查

| 变更对象 | 必须检查的下游 |
| --- | --- |
| 需求/安全状态 | 架构、原理图、软件、测试、说明和生产 |
| 器件/封装/BOM | 原理图、PCB、驱动、功耗、热、采购和测试 |
| 引脚/时钟/电源 | 板级配置、驱动、启动、低功耗和产测 |
| 协议/接口 | 生产者、消费者、版本、存储、日志和兼容测试 |
| 存储格式/分区 | 迁移、掉电、回滚、旧固件和恢复工具 |
| 工具链/SDK/EDA | 可复现构建、生成物、告警、ABI 和发布清单 |

AI 只需检查实际可能受影响的下游，但必须说明排除其他项的依据。
