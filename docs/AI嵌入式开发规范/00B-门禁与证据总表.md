# 门禁与证据总表

本文件只负责F0-F7、G0-G5、B0-B4、E0-E5及阶段到目录分支的只读映射。目录分类、创建条件、迁移和验收的唯一正文归10；本表的目录位置不授予任何目录或Git操作权限，冲突时以10为准。

| ID | 触发条件 | AI必须执行 |
| --- | --- | --- |
| M-GATE-001 | 开始或结束任一阶段 | 按总表检查输入、阻塞、交付物、证据和关闭条件 |
| M-GATE-002 | 前置门禁未关闭 | 停在当前阶段，只输出未关闭项和恢复条件，不进入下一阶段 |
| M-FLOW-004 | 发现前置事实错误 | 退回事实所属阶段，保留历史记录并重做受影响检查，不在后续阶段掩盖 |

## 2. G0-G5门禁

| G门禁 | 允许推进到 | 不满足时 |
| --- | --- | --- |
| G0 概念评估 | 可行性和候选方案 | 不承诺实现、成本和交期 |
| G1 需求基线 | F2正式架构 | B1未关闭不得进入正式架构 |
| G2 架构基线 | F3详细设计 | B2保持候选，不冻结选型和接口 |
| G3 详细设计 | F4实现/制造准备 | 关键参数未知不生成正式制造包 |
| G4 样机执行 | F5/F6实物验证 | B3未关闭不制板、上电、烧录或部署 |
| G5 发布生产 | F7发布、试产和生产 | B4未关闭不试产、不认证、不发布 |

## 3. B0-B4阻塞

| B等级 | 影响 | 处理 |
| --- | --- | --- |
| B0 不阻塞 | 不影响当前结论 | 记录后继续 |
| B1 阻塞需求基线 | 目标、用户、范围或验收不明确 | 不进入正式架构 |
| B2 阻塞设计冻结 | 接口、电源、环境、资源、安全或结构参数不明确 | 可做候选，不冻结设计 |
| B3 阻塞实物操作 | 目标板、板版、供电、恢复或安全条件不明确 | 不制板、不上电、不烧录、不部署 |
| B4 阻塞发布 | 测试、法规、生产、签名、批次或批准不明确 | 不试产、不认证、不发布 |

## 4. E0-E5证据

| E等级 | 可以证明 | 不得替代 |
| --- | --- | --- |
| E0 静态 | 检查范围内的代码、设计、计算和连接成立 | 构建、时序和实物行为 |
| E1 工具检查 | 构建、链接、打包、ERC/DRC或输出完成 | 目标设备或样机正确 |
| E2 主机/仿真 | 算法、解析、回放或模型条件下行为 | 真实电气、ABI、热和长稳 |
| E3 台架/样机 | 指定板卡、固件、配置和仪器下行为 | 整机环境和批量一致性 |
| E4 整机/环境 | 指定整机、环境、现场或长稳条件 | 认证、量产和所有批次 |
| E5 受控发布 | 指定试产、认证、量产或发布批次 | 未覆盖版本和后续变更 |

## 5. 门禁输出

```text
[阶段门禁]
当前/目标：G? / F?
输入基线：<版本>
阻塞：<B0-B4或无>
交付物：<TPL编号及路径>
证据：<E0-E5、对象版本和位置>
关闭条件：<只列失败或未关闭项；全部关闭写“已关闭”>
结论：通过 / 失败 / 阻塞
允许进入：<唯一下一阶段或不允许>
```

AI不得自行给出“有条件通过”绕过B1-B4；目录职责执行10，操作权限执行00C。
