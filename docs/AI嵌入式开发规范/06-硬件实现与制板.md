# 硬件实现与制板

## 快速摘要

- 解决PCB布局布线、制造输出与样机版本控制问题。
- 在F4硬件实现、制板输出或已制板设计变更时读取。
- 原理图和器件详细设计读取[04-详细设计.md](04-详细设计.md)。
- 读完必须产出PCB检查记录或制造输出记录，并按[09-交付物模板库.md](09-交付物模板库.md)填写。

## 任务路由

| 当前任务 | 只读章节 |
| --- | --- |
| PCB规则与布局 | 1 |

## 不读本分册的情况

- 当前阶段未触发F4硬件实现或制板任务。
- 交接包已说明阶段未变且没有新增PCB、制造或样机未知项。
- 普通代码修改不读本分册。

## 1. PCB 规则与布局

| ID | 触发条件 | AI 必须执行 |
| --- | --- | --- |
| M-HW-PCB-001 | 建立板规则 | 从板厂能力、法规、电压、电流和接口要求确定叠层、铜厚、线距、孔径和阻抗 |
| M-HW-PCB-002 | 初始布局 | 先固定结构、连接器、安装孔、禁布、安全和散热，再放电源/时钟/高速/模拟/射频 |
| M-HW-PCB-003 | 去耦布局 | 器件靠近对应电源脚，电源-电容-地回路短且不与其他回流共享瓶颈 |
| M-HW-PCB-004 | 开关电源 | 识别高 `di/dt` 环路、开关节点、反馈和散热路径，按手册控制面积与耦合 |
| M-HW-PCB-005 | 晶振/参考/高阻/射频 | 远离噪声源，满足参考地、屏蔽、禁布和匹配器件可调要求 |
| M-HW-PCB-006 | 发热与温敏器件 | 计算损耗和热路径，避免未经分析的热耦合，并预留测温条件 |

## 2. 布线、回流与电流

| ID | 触发条件 | AI 必须执行 |
| --- | --- | --- |
| M-HW-ROUTE-001 | 关键信号 | 确保连续参考平面；跨分割、换层和连接器处处理回流 |
| M-HW-ROUTE-002 | 差分/高速/时钟/存储/射频 | 按接口规范设置阻抗、长度、时延、间距、过孔和拓扑，不套固定经验值 |
| M-HW-ROUTE-003 | 电源/大电流 | 按电流、允许温升、压降、铜厚、过孔和故障电流计算 |
| M-HW-ROUTE-004 | 模拟与数字邻近 | 根据耦合和回流布局，不任意切割地平面 |
| M-HW-ROUTE-005 | ESD/浪涌入口 | 保护器件靠近入口，泄放路径短且不穿过敏感区域 |

## 3. 制造输出与样机

| ID | 触发条件 | AI 必须执行 |
| --- | --- | --- |
| M-HW-OUT-001 | 输出制造包 | 确认 BOM、坐标、装配图、网表、Gerber/ODB++、钻孔和说明来自同一版本 |
| M-HW-OUT-002 | 交付板厂前 | 执行 ERC、DRC、未布线、网络一致性、库、3D/结构和板厂能力检查 |
| M-HW-OUT-003 | 存在检查豁免 | 逐项记录位置、理由、风险和批准，不得批量忽略 |
| M-HW-OUT-004 | 首件/样机验证 | 按电源、时钟、数字、模拟、热、EMC/ESD/射频和产测保存原始证据 |
| M-HW-OUT-005 | 修改已制板设计 | 记录返工范围、板号、风险、验证和是否允许进入下一版 |

AI 只能报告实际运行的检查。未运行的板厂 DFM、SI/PI、热、EMC、安规或实测必须列为待验证。
