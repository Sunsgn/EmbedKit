# 交付物模板库

## 快速摘要

- 提供输入、需求、接口、设计、验证、发布和风险交付物的填写骨架。
- 仅在当前动作需要创建或更新交付物时读取对应模板。
- 读完必须按真实输入与证据填写模板，不得代填结论或批准。
- 交接包唯一模板见[00D-交接包与状态模板.md](00D-交接包与状态模板.md)。

## 任务路由

| 当前任务 | 只读模板 |
| --- | --- |
| 输入与立项 | TPL-01、TPL-10 |
| 需求与架构 | TPL-02～TPL-04 |
| 原理图、PCB与制板 | TPL-05～TPL-06 |
| Bring-up与测试 | TPL-07～TPL-08 |
| 发布 | TPL-09～TPL-10 |

## 不读本分册的情况

- 当前动作不创建或更新交付物。
- 交接包已指向已存在且格式未变化的模板实例。
- 普通代码修改不需要新增交付物时不读本分册。

本模板库只提供骨架。AI 必须用真实输入、实际结果和可追溯位置填写；未知写“未知”，未执行写“未执行”，不得代填结论、批准、签名或测试结果。
