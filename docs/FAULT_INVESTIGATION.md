# 故障调查工作区

故障调查工作区把已有的 HardFault、ELF/DWARF、MAP、CMSIS-SVD 与自动化测试记录串成一份可保存、可复测、可导出的调查档案。原有工具仍可独立使用。

## 使用流程

1. 在“嵌入式工具箱 → 故障调查”粘贴 Cortex-M HardFault 日志，或从 HardFault 工具点击“创建故障调查”。
2. 核对提取的 R0–R3、R12、LR、PC、xPSR、CFSR、HFSR，以及可选的 MMFAR/BFAR。
3. 通过 Local Agent 选择与设备固件对应的 ELF/AXF；按需导入 MAP 和 CMSIS-SVD。
4. 填写设备实际固件 SHA-256，然后执行调查。
5. 查看函数、DWARF 源码行、反汇编指令、MAP 交叉证据、SVD 地址匹配、冲突、未知项和可信度。
6. 关联修复前及修复后的自动化测试记录，保存调查并导出 JSON 或 Markdown。

## 证据与降级规则

- ELF 精确符号和 DWARF 行表属于确定性地址映射；MAP 用作独立链接布局证据。
- Cortex-M 代码地址的最低位可能是 Thumb 状态位。系统保留原值，并使用清除最低位后的地址查询代码。
- BFAR/MMFAR 匹配到 SVD 外设或寄存器只表示地址范围吻合，不能单独证明根因。
- ELF 与 MAP 符号不一致时同时保留两份证据并显示冲突。
- 设备固件 SHA-256 与 ELF SHA-256 不一致时，源码定位可信度自动降级。
- 本机没有适用的 `objdump` 时，仅反汇编能力降级；ELF 符号、DWARF 和 MAP 定位仍可使用。
- AI 建议只能作为 `external-ai` 或启发式结论加入，不能覆盖确定性结论。

## 数据与资源限制

- 原始故障日志最大 1 MiB。
- MAP 最大 16 MiB，SVD 最大 10 MiB。
- 单份调查最多保存 500 条地址解析结果，本地最多保存 100 份调查。
- 调查导入文件最大 4 MiB。
- Local Agent 的 ELF 分析会话有有效期；历史档案保存查询快照，不保存 ELF/MAP/SVD 原文件和临时授权令牌。
- 导出时会缩短 DWARF 中的绝对源码路径，不导出完整构建产物。

## 反汇编边界

Local Agent 使用参数数组和 `shell: false` 调用已安装的 GNU/LLVM `objdump`，单次只读取目标地址附近的有限窗口，设置 5 秒超时和 256 KiB 输出上限。工具缺失、架构不支持或目标地址不在指令边界时会返回可恢复的降级状态。
