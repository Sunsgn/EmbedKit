# 工程中心：本地嵌入式项目工作台方案

更新日期：2026-10-15

## 目标与边界

工程中心用于管理大量已有嵌入式项目，而不是替代 Keil、IAR、厂商配置工具或 Git。用户选择一个真实本地目录后，EmbedKit 保存可复现的工程识别摘要、相对路径证据、环境需求和构建产物元数据，并提供到工程分析、开发环境和资料中心的可选跳转。

工程中心不维护设备、串口或通信通道关联；通信调试、集成测试、工程分析、工具箱和资料中心继续可以独立使用。

## 用户闭环

1. 用户在工程中心选择本地目录；网页不能提交任意路径，必须经过 Local Agent 系统选择器授权。
2. Local Agent 在授权目录内执行有界扫描，识别 IDE、构建系统、框架/RTOS、芯片候选和构建产物。
3. 页面展示每项结论的相对文件路径、可信度、未知项、扫描覆盖量、截断状态和警告。
4. 用户保存工程说明、程序功能、标签、分组和环境需求；确定性扫描不得自动生成“已验证”的程序功能。
5. 用户可重新定位并扫描；扫描失败时保留上一次成功结果和本地源码，不做破坏性修改。
6. 用户可导出便携工程档案，带走识别摘要与相对路径证据，但不包含绝对路径、授权令牌、源码或固件内容。

## 输入、输出与资源上限

输入是用户明确选择的一个本地目录，或兼容的工程档案 JSON。扫描输出为 schema v1 结果；工程持久化模型为 schema v4。

默认扫描上限：5,000 个文件、12 层目录、800 条结构预览、500 个识别证据、500 个构建产物元数据、10 秒。`.git`、`node_modules`、常见缓存和构建目录不会递归；符号链接不会跟随。达到上限时结果标记为截断，不把“未发现”表述为“确认不存在”。

识别仅使用本地确定性规则。支持 CMake、Make、Meson、PlatformIO、Keil、IAR、Eclipse 系工程以及 FreeRTOS、Zephyr、RT-Thread、ThreadX 等标记；未知工程降级为通用嵌入式源码工程，并明确列出未识别项。芯片文件名推断只标记为候选，不能当作已确认型号。

## 数据与隐私

- IndexedDB 保存工程 v4 摘要；v3 在数据库升级或读取时迁移，v1/v2 旧设备项目仍可导入，但设备和通道字段不迁移。
- 本机绝对路径单独保存在浏览器本地绑定表，以稳定工程 ID 为键，不进入工程 JSON 或工作区便携备份。
- Local Agent 目录授权令牌只存在内存中，15 分钟过期；一次扫描结束后页面主动撤销。
- 工程删除只删除 EmbedKit 记录和本地绑定，不删除用户目录或任何源码。

## 失败与恢复

- Agent 离线：历史识别结果、说明和导入导出仍可用；选择目录和重扫禁用并显示恢复说明。
- Agent 版本不兼容：提示升级，不降级为网页任意路径读取。
- 用户取消选择：不创建项目，不改变当前结果。
- 路径消失、权限拒绝、扫描超时或文件变化：显示具体错误，保留原结果，用户可重新定位。
- 数据损坏或超限：模型规范化拒绝导入，不静默丢弃证据。

## 验收

- 空数据库不自动创建演示工程。
- 真实临时目录样本可识别构建系统、RTOS 标记与固件产物，并返回相对路径证据。
- 未知项目、资源截断、符号链接、Agent 离线和取消选择均有安全降级。
- 工程导出不包含本机绝对路径，v3 工程与 v1/v2 旧设备项目兼容迁移。
- 工程说明、程序功能、环境需求和资料入口保留；不恢复设备或通道关联。
